# 旧稿导入：保留原件，带证据逆向建档

## 先对稿，不先改稿

按作者指定的来源读文件，不把题材笔记、废案或备份当正文。对照 [SB §2](formats/project.md) 列映射：原路径与原卷章标识 → 目标书根相对路径 → 采用哪版 → 已发布／未发布／待确认。发现卷内章号重置、序章、番外、跳号或同章多版本时，将冲突放到同一批请作者确认全局章号和采用稿；合法的第 0 章不要擅自改成第 1 章。没有可靠的章节边界或纯文本需转码、拆章时，先出方案，不动原始文件。

优先复制作者确认的采用稿，不移动或重命名原件；同一路径已存在且内容字节相同则复用，有差异就停，不覆盖，也不擅自开新稿次来绕过冲突。目标目录已有多个稿次时，按 [SB §7.1](formats/chapter.md) 核对脚本选中的定稿是否与作者选择一致；若不一致，请作者决定如何处理，不伪造章纲。已发布章默认只从原件复制对应发布稿；其他版本原处保留。既有冻结章不得新增稿次或改正文。

冻结范围按 [SB §8](formats/config.md) 写作者确认且已核对路径和采用稿的公开章号；合并连续区间，空档分开。原件字节可直接比较时，复制后对照字节；有拆分、格式转换或找不到发布版的疑问时先停，不把不明版本封成发布稿。基线发现格式问题只登记，原稿不变。

## 按章提取，再跨章验一遍

第一遍按全局章号读定稿，每章只摘有证据的候选；记书根相对路径和行号或段落定位，配一句短证据，不抄整章。第二遍按人物名/别名、物件或承诺、时点用语及支线目标跨章复查，回看当前导入终点；不能声称已经扫描未读的章。没有读完的区间单列覆盖范围。

| 类别 | 怎么找和复核 | 确认后写哪里 |
|---|---|---|
| 人物 | 从有行动或对白的人物入手，记首次实际出现和文本中稳定的身份。按别名回搜上下文；只有同场称呼、角色自述等证据指向同一人时才建议归并。传闻、提及与在场分开，临时情绪不当作性格；秘密分开写「读者已知」和「作者真相」。 | `bible/characters.md`；角色关系与一时状态不是稳定档案。 |
| 时间锚点 | 先找明写的钟点、节气、前后顺序及「三天后」「月底前」等间隔或期限，再从最近的已知时点向前/向后推。把叙事章序与故事内时序分开，标注回忆或倒叙。正文可校时的记硬锚候选，模糊回忆记软锚；只知上下界记窗口，约定截止记期限。两处相对时间推不拢就列两边证据，不硬算日期。 | `bible/timeline.md`；保留内部能证实的精度和正文措辞。 |
| 未结伏笔 | 标记已服务当前场景但仍带问题的细节：反复出现的物件、不合常理的反应、明确却未兑现的承诺、只揭一层的解释。顺着同物件、换称呼和因果后果回搜首次埋设、后续触及及可能的收束。已经解释且产生结果的不算未结；单次气氛细节不自动算埋设。分别记录文本已给读者的解释、作者确认的真相、以及未来由谁／通过什么载体揭示。后两项不明就做待问项，不编回收章或未来场景。 | `bible/foreshadows.md`；缺机读必填信息留在草稿。 |
| 支线 | 从反复出现的角色目标或冲突入手，逐章找发生改变的动作，不把同一段复述当作又推进了一步。写出这条线如何推动、阻碍或改变主线；做删除测试：拿掉它会改变主线哪一步？按已证实的推进定位种因、提醒、连环、误导、小收、大收；缺的步骤留缺，不假定已做。跨多卷挑战主线的候选 A，主要服务本卷的候选 B，单章到三章的候选 C；没能挂靠主线的先不入表。 | `bible/subplots.md`；伏笔用确认后的 ID 引用，不把伏笔描述再抄一遍。 |

## 标置信度，按项确认

在 `bible/drafts/` 用自然文字列候选项，编号只用于本批确认，不占正式 ID。每项写：来源、证据、事实或推断、置信度、尚缺信息、拟写入口。**高**：正文明说或场景直接展示且无冲突；**中**：有两处以上相互支持的暗示，但需解释；**低**：孤证、传闻、说法矛盾或需要倒推。置信度衡量证据，不代表授权。例：对白里某人说「月初就到了」，高置信的是「此人这样说过」，不是到达日期。

给作者摘要：扫描范围、每类候选数量、代表条目与定位、冲突证据两边、缺什么才能入档。请作者按编号选「合入／修正后合入／留待确定」。确认后对照 [SB §6](formats/bible.md)、已登记主写入口和既有行，复用已确认的别名和 ID，不整表替换。无论置信度多高，未经确认都不写入正式档案；冻结稿与档案矛盾时保留读者看过的正文，交由作者决定档案或后续章节的解释。
