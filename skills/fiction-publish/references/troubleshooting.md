# 发布异常恢复

先判断页面现在是编辑器、弹窗、草稿箱还是章节管理，再决定下一步。每次恢复只处理已授权的动作；未知审核错误、风控、平台限制、登录失效或验证码出现时立即停止提交，保留页面和日志，交给作者。不试探绕过，也不把常规提示自动当成错误：看清它是否阻止继续，并以列表核验为准。

## 连接、标签页与控件

| 现象 | 恢复动作 |
|---|---|
| 找不到原页或标签列表为空 | 先保留当前会话，重新枚举作者打开的标签并按当前工具文档绑定正确的作者中心页，稍等后再查一次。空列表不证明断连。只有已获授权才在同一作者浏览器另开窗口查证；仍无可读页面就停。 |
| 明确断连，或浏览器未开启 | 等待后试一次轻量只读操作；仍失败就按当前宿主说明做只读诊断，请作者打开正确的浏览器会话或恢复连接。重连后重新识别页面、作品和最后一章状态，不能沿用旧标签 ID 或历史路径。 |
| 扩展或连接组件异常 | 告知作者具体诊断结果，由作者恢复。不要自行安装组件、改浏览器配置，或用其他控制途径接管已登录会话。 |
| 控件找不到、位置变了或有多重匹配 | 重新观察 URL 和可见界面；查遮挡弹窗、加载、目标标签、标题与正文是否为空。按当前可见文字、标签和当前弹窗范围重新定位；不按历史序号、不强点、不调用隐藏接口。普通控件原因明确后最多重试一次，再回读界面；提交按钮不适用这条。 |

只在新编辑页已绑定且作品已核对后处理授权可关闭的旧页，不关不明标签。未经作者同意，不刷新可能有未保存内容的编辑页。作者要求关闭且不保存时不主动点「存草稿」；自动云端保存可能早已发生，关闭不是回滚。不自行删草稿或覆盖作者另一页的内容。

## 正文、字数和字段

- 字数为零、缺失或像上一章：等保存与计数更新，重读当前编辑器的计数和章号，核对正文首尾；仍不稳定就停。
- 章号或标题丢了：只补缺失字段并复核正文，不重复粘贴。作者接管时先查实当前稿，只有确定内容丢失且有获准的源稿才恢复，不拿本地旧稿覆盖作者改动。
- 列表字数为 `-`：用日志里能对应到同一提交稿的编辑器平台计数。没有可信记录时，通过可用的编辑入口只读核查，不改动、不触发提交；无法读取则标未知，不把 `-` 当零。

## 提交反馈与重试

最终点击后立即读消息区、通知或弹窗，必要时用宿主允许的页面快照保留提示原文，再等页面更新。不要搜整篇正文里的「失败」「重复」来猜提示。页面无反馈、工具超时或结果丢失，都可能发生在服务端已接受之后。

| 看到的证据 | 下一步 |
|---|---|
| 章节管理有唯一目标行，身份、卷、目标时间和提交状态均符合 | 停止点击，更新原行并继续；即使原编辑页仍开着也不重提。 |
| 明确被拒，仍在发布设置，原因已知 | 记原文；需要改字段时取消该层设置，回编辑器只做已授权的修正，再完整走检测和设置。未知审核错误或风控不重试。 |
| 按钮仍处理中、页面尚未更新 | 等待并重读。不中途连点，不直接刷新有未保存稿件的编辑页。 |
| 突然跳页、工具报错、没找到列表行 | 重枚举标签，查对作品、筛选、排序、分页、搜索、分卷，再查草稿箱；不能仅凭首行为空、草稿仍在或按钮恢复可点击就断定失败。 |
| 有明确证据表明未受理，且无处理信号、未找到同章提交 | 在同一记录下按授权处理原编辑页或已确认的唯一草稿。重新核对所有设置并落盘 `待核验`，同一次提交最多再尝试两次；在备注累计次数，重连不清零，每次都重新核验。仅凭沉默不重试。 |
| 仍无结论，或草稿和列表存在身份不明的副本 | 保留现场和 `待核验`，写明已查内容、章号和目标时间，请作者核实；不进入下一章。 |

## 恢复草稿

1. 先查章节管理，排除已提交，再在草稿箱用作品、章号、标题和可见 ID 确认唯一目标。核不清就停。
2. 获准恢复后，从该条草稿的「编辑」入口进入，核对源稿、当前正文、标题、卷及平台字数。从「下一步」按已确认参数重走检测和发布设置；最终点击仍受本会话批次授权约束。
3. 回章节列表核验后更新同一日志行。草稿箱结果可能滞后，可重读列表复核。完整恢复一次仍只有草稿，或有多份身份不明记录时，暂停请作者处理；不新建、不自删副本。

## 已提交但日期不符

1. 在正确作品中定位原章，记下平台当前显示的时间及作者已确认的目标。改期前预算原日和目标日的新总量，并检查相邻章的发布时间仍按章号非递减。报告受影响章；设有日阈值才算预计缺口。
2. 只有获准改期且平台允许时，从原章的「编辑」入口核对正文，重走检测与发布设置，只改已授权的日期时间；最终确认后回列表核对仍是原章、时间确已改变。只点日历不算完成，不能另发同名章代替。
3. 更新原行，重算原日与目标日。原日有阈值且未达标时，只有按序下一章也在既有补排授权内、且符合日期及篇数约定才补排；未设阈值时不因字数自动补排。需要再移动其他已核验章时，先列出章号、改期前后时间、各日新总量及顺序；无覆盖该方案的授权就停。不自行滚动重排整批。已提前公开、编辑入口不可用或目标日不可选时，交作者处理。

## 报大段落重复

这不是普通错字提示，不能用 `typo_prompt=submit` 略过。记录错误，取消发布设置回编辑器，先保留可恢复副本并比对源稿，确认是否是重复粘贴、源稿本身重复，还是作者已在线作过修改。

1. 找出确切的重复连续段落，保留一份完整内容。仅在作者明确授权删重时删确认的重复副本；不全局删除相同短句、有意复沓的对话或叙述，不补字、不替换、不改写。无法确认删哪段就列候选并停。
2. 比对差异只有授权内的删除，复核衔接、标题和正文首尾；读删重后的平台字数，重算该日期。记删除位置、原因及前后字数。
3. 网页重复粘贴只修待发布副本，不改源稿。源稿本身需要同步删除时，仅在作者另行明确授权修改该稿且未冻结时同步；否则把差异交作者处理，不能静默分叉。
4. 从「下一步」重走检测与设置，核对日期和卷，获准后提交并核验。仍报重复则找具体证据；没有新的明确重复就停，不试删无关内容。

## 卷不生效或必须交还作者

建卷后看不到新卷，先重开分卷管理核查是否遗漏底部确认，不能马上重建。卷已存在但当前章仍显示旧卷，取消发布设置，从编辑器重选卷并确认，再重走检测；复核后仍无效就停。

交还时写明章号、卷名、目标时间、可见错误原文、已查或已做的恢复、提交结果是已知还是不确定，以及需要作者决定的一件事。若发现明确阻碍记 `受阻`；提交可能已发生但尚无结论时保留 `待核验`。作者接管后重新观察，不沿用接管前的页面假设。
