# 平台适配说明

目前只有 `fanqie`（番茄小说）。未支持的平台只做离线准备，不用相似按钮猜发布路径。新增平台时：

1. 在此目录加对应平台 ID 的 Markdown 适配页，并在 `SKILL.md` 的参考表增加直达入口。页首标实验性与最近实测日期；没实测就留待填，不借用其他平台的日期。
2. 说明如何确认作品、定位章和草稿、读取平台字数、对应 `publish.*` 选项、选择完整日期时间、建卷与切卷。对不支持或含义不等价的选项写明停止条件，不自行替换。
3. 说明最终按钮、提交回执、列表核验字段、平台状态原文及与流程状态的区别；写出已知恢复分支与哪些情形要交还作者。
4. 沿用同一份日志、去重规则和批次授权闸口，不另造账号凭据配置。实际验证需用获授权的作者会话，遵守平台限制；没有验证过的路径如实标注。
