# 番茄小说适配（实验性）

平台 ID：`fanqie`。最近实测日期：`待填写（YYYY-MM-DD）`。以下是已知界面线索，不是现行界面的保证。使用作者已登录的作者中心，从可见页面识别控件；界面不符时先查明作用，不能猜测或跳过平台要求。

## 进入作品和填写章节

1. 在章节管理页核对作品名和可见作品标识，确认目标章没有已经提交的记录。同一章有草稿则查清身份，不开第二份。
2. 点「新建章节」后重读当前页；若另开编辑页，先绑定新页并确认作品，再按授权处理旧标签页。若当前页已变编辑器就保留。草稿可能自动保存。
3. 填章号、去掉章号前缀的标题和清理后的正文，检查卷、首尾和粘贴次数。读取编辑器左上角当前稿的「正文字数」，别把「上次提交」的章号或仍未刷新的数字当字数。等稳定非零后才继续。

## 检测与发布设置

每次点完重读当前界面。下面的提示可能省略或换顺序，不能预排一串点击。

1. 点「下一步」。若出现「检测到你还有错别字未修改，是否确定提交？」且确认它只是检测前的提示，`typo_prompt=submit` 才点提示里的「提交」，`stop` 则记录提示、停下请作者核稿。如果无法确认该按钮是否会直接对外提交，不把它当普通提示。
2. `basic` 选「仅基础检测」或当前界面明确的等效选项。若另弹出「是否进行内容风险检测？」且当前提示明确是在询问是否**另做可选检测**，`basic` 可点这层的「取消」；不要取消后台强制检查，也不要误关「发布设置」。`full` 则选完整检测，或在这层选择执行并等结果；不能自行降级。确认最终进入「发布设置」。已识别的纯说明通知可用「我知道了」关闭；若提示是未知审核错误、账号风控或平台限制，记原文并停。
3. 在「发布设置」核对卷名和章号。按 `ai_disclosure` 如实选「是」或「否」；按 `preview_keyword` 填字面值，只有明确为 `""` 才留空。定位与「定时发布」文字对应的开关，用可见状态或 `aria-checked` 复核，不按全局开关序号猜。定时时确认日期与时间两个输入框已出现；即时提交确认开关关闭，并且作者授权的是即时提交。
4. 展开日历，先读面板所示年、月，再按差值逐月前进或后退，每次确认面板确实切换。跨年要校对年份。到了目标年月，只点属于本月的目标日，不点灰显的相邻月同号日期。若不可选，不绕过限制，也不自选替代日。
5. 收起日历后重读输入框：日期须与完整目标 `YYYY-MM-DD` 相符，时间须等于已授权的 `HH:MM`，按平台显示的时间口径解释。页面默认时刻与任务冲突、时间口径不清或选择回弹时先停。若出现定时日期「超过7天」的常规提醒，且未阻止提交，不直接判失败，仍以章节列表核验为准；若确实限制提交则停，不绕过。选了日期不等于提交。
6. 完成批次授权检查和点击前的全字段核对，把 `待核验` 落盘，再点发布设置底部「确认发布」一次。立刻看提示并等跳转。回章节管理找到该章，核对章号、标题或 ID、分卷、完整日期时间及状态，不把编辑器云端保存提示当发布成功。

## 创建及切换分卷

1. 确认下一章的源稿及对应线上卷名。进列表的「编辑分卷」，查有无既有同名卷；断线回来先重查。有卷就用原卷，不重复建。
2. 新卷在授权内且确实不存在时，点「新建分卷」填已确认卷名。核对授权后点输入框旁的绿色对勾，确认新卷行出现；再按授权点弹窗底部可见的「确定」，不要用右上角关闭代替保存。重开分卷列表确认新卷存在且唯一。
3. 建卷不等于当前章已经切卷。新编辑页可能默认旧卷；若「发布设置」挡住编辑器入口，取消这层设置，再点编辑器左上角卷名，选新卷并点底部「确定」。先在编辑器左上复核，再从「下一步」重走检测，不能沿用切卷前的设置结果。
4. 提交前在发布设置再次核对卷，提交后去对应分卷列表核验。卷不明或选择不生效就停，不用下一章试错，不重置当前日期的字数。
