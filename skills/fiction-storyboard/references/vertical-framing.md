## 一、9:16 竖屏与横屏的核心差别

本套件默认画幅为 `9:16`（配置键 `visual.aspect_ratio`，可在 `visual/assets.md` 的 `画幅` 按剧覆盖，见 [SB §8](formats/config.md)、[SB §9.4](formats/storyboard.md)）。手机全屏竖看带来三个直接约束：

1. **横向窄、纵向高**：横屏里自然排开的三人并肩站位，放进 9:16 会把人物挤成细条；因此默认单镜人数上限是 `storyboard.max_people = 3`，日常尽量 1–2 人同框。
2. **上下两端容易空**：如果只把人物摆在画面正中拍远景，上方是大片天花板或天空、下方是大片地板，手机上看人物小到看不清表情。
3. **手机观看距离近、停留短**：观众优先读人脸、手部动作和核心物件，主力景别应偏紧（多用中景、近景、特写），靠景深层次交代环境。

## 二、用纵深和动作代替空荡远景

- **少摆无人空远景定场**：不要为了“交代地点”专门塞一镜 3 秒的空房间或空街道远景。除非空间距离直接决定追逃输赢或复杂多人走位，否则改用**带人物动作的中景 / 全景**进场。
- **借人物入画带出环境**：让人物推开毛玻璃门、撑住木柜台、端水盆走出后门，在人动的过程中顺带扫出柜台、后墙木板缝、窄巷砖墙等地点锚点。
- **前中后景三层拉纵深**：竖屏缺左右宽度，就要靠前后层次立体起来。
  - **前景**：门框一角、旧木柜台边沿、台灯灯罩轮廓、听者虛化的肩膀（压住画面下沿或左右一侧，避免上下空荡）。
  - **中景（焦点主体）**：说话人、发力的手或核心道具，落在画面中上三分之一到中段（避开手机播放界面底部字幕与操作条遮挡区）。
  - **后景**：能认出地点的固定陈设与实景光源（如后墙木板墙、尽头昏黄路灯），用浅景深适度虚化，不抢主体。
- **慎用大幅俯仰**：竖屏上下窄长，过度仰拍或俯拍容易拉变形人物头身比例。要表现强弱压迫，优先靠**站坐高低差、前后距离（近大远小）和正面 / 斜侧角度**，确实需要强调孤立或碾压时再加轻度俯仰。

## 三、竖屏双人对话与空间关系

- **拒绝扁平并排站桩**：两人并排站在同一平面拍双人中景，竖屏里两人各占半边窄条，既看不清神情，又浪费上下空间。
- **用前后错位与正反打**：
  - **斜向纵深双人镜**：一人靠前景背侧（过肩虚化），另一人居中景面向镜头，隔着柜台或桌面形成压迫或对峙。
  - **单人近景正反打**：切回各自单人近景，保持同一条轴线（A 始终朝画面一侧看，B 始终朝另一侧看），靠 `段` 里的 `站位` 锚定两人相对位置（如“林砚在柜台里侧，唐七在柜台外靠门一步”）。
- **道具做视觉桥**：两人争执的核心物件（停摆的座钟、桌上的旧钥匙）放在前景下沿或单独插特写，帮观众一眼把对话和物件勾连起来。

## 四、在 `画面` 自由文本里写机位、角度与焦段

契约刻意只设三张闭集词表（`景别`、`运镜`、`转场`，见 [SB §9.6](formats/storyboard.md)），不把机位、角度、焦段拆成一堆必填列，以减轻手写负担；这些信息直接融入 `画面` 自由文本开头，用自然、能指导取景的话写清四件事：

| 维度 | 常用写法 | 戏剧作用 |
| --- | --- | --- |
| **水平角度** | 正面 / 斜侧（四分之三侧） / 正侧 / 后斜侧 / 背面 | 决定观众看清几分神色，以及是否藏住面容 |
| **机位高度** | 贴地 / 略低机位 / 平视 / 略高机位 / 顶拍 | 平视表对等，略低带压迫，略高显孤立或俯看桌面物件 |
| **焦段与景深** | 广角（24–28mm，拉大纵深与空间感）/ 标准（35–50mm，自然透视）/ 中长焦（85mm 以上，压缩背景、浅景深剥离人物或特写物件） | 控制空间距离感与主体聚焦度 |
| **实景光位** | 紧扣地点原有光源（如“柜台左端暖黄台灯照亮半边脸”“巷尾路灯从背后勾出轮廓”） | 保证同场跨镜光影连戏，不写“氛围感很强”这类空词 |

写法要点：

- **不用生图模型看不懂的调度黑话**：`画面` 最终要喂给下游写提示词，写「越过木柜台边沿的斜侧平视，50mm 标准焦段」，不要只写「轴线右侧反打镜」。
- **标清焦点落在哪**：前景遮挡时顺手写明「前景虚化，焦点落在中景林砚眉眼」或「焦点钉在表盘三点十分的指针上」。
- **顺手兼顾安全区**：重要表情与特写物件尽量落在画面垂直中上部到中央，底部留给前景桌面、衣襟或自然暗部，方便成片放字幕。

## 五、改写对照：从抽象套话到可拍画面

| 写得太虚（难以出图或构图发散） | 改成竖屏可拍的 `画面`（兼顾构图与起止） |
| --- | --- |
| `林砚在钟表铺里看座钟，气氛压抑。` | `略低机位斜侧平视，50mm 浅景深。旧木柜台横在前景下沿，暖黄台灯从一侧照亮白底座钟和林砚半边脸；林砚站在柜台里侧垂眼盯着表盘，右手从身侧抬起伸向分针，指尖将碰未碰。` |
| `两人在后巷里说话，很紧张。` | `过肩斜侧平视，85mm 压缩纵深。前景左侧是唐七虚化的旧夹克肩背，后方旧砖墙夹出昏暗窄巷，尽头路灯在潮湿地面拉出冷光；中景林砚站在两步外迎着来向站定，抬眼直视唐七，双手插在工装兜里一动不动。` |
| `特写钥匙。` | `略高机位俯拍，85mm 极浅景深。昏黄台灯打亮深色木台面，一把沾满暗绿铜锈的拇指长黄铜钥匙静置在台面中央；一只带旧疤的右手捏着软布从画面一侧探入，按住匙柄顺势一擦，匙柄露出一截黄铜本色。` |
