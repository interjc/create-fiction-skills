## 一、三层边界：什么写进资产库，什么留给分镜

`drama/{series}/visual/assets.md` 只记录“能画出来、能拿成片核对”的固定可见外观，严守三层切分（[SB §9.4](formats/storyboard.md)），不把同一件事在资产、连戏表、分镜里抄三遍：

| 类别 | 第一层：固定本体（`### 名称`） | 第二层：阶段造型 / 状态（`### 名称@变体名` + `continuity.md`） | 第三层：单镜动作与构图（分镜 `画面`） |
| --- | --- | --- | --- |
| **人物** | 年龄段、体型、五官骨相、发型发色、永久疤痕或印记 | 阶段服装鞋履、跨场持续伤污包扎、雨衣 / 易容 / 遮挡版 | 当镜神情、站坐姿态、视线朝向、左右手拿什么、景别 |
| **地点** | 空间格局、出入口连通、主要材质、3–5 个固定锚点 | 停电、被翻乱、雨夜积水、白天 / 夜晚不同照明格局 | 单镜机位高低、焦段选择、镜头里谁站在哪 |
| **道具** | 尺寸参照、形状结构、主体材质、永久印记 | 损坏、断齿、染血、翻开 / 背面、去锈显字 | 哪只手拿握、递接过程、放在画面哪一角 |

**变体继承规则**（[SB §9.4](formats/storyboard.md)）：`名称@变体名` 自动继承同名本体条目的全部字段；变体里只写与本体不同的部分，写出来的同名键（即使值为空）会覆盖本体。

## 二、分镜阶段与提示词阶段的严格分工

`visual/assets.md` 按两阶段维护，本 skill 严格守住边界，不越界代工：

1. **分镜阶段（本 skill）**：**只建最小条目**。保证本集分镜里引用的每一个 `人物`、`地点`、`道具`（含必要变体）在 `assets.md` 中都有对应 `### {资产键}` 和一行具体可见的 `- 外观：`，使 `storyboard-check.mjs` 的 `sb-asset`、`sb-spoiler`、`sb-continuity` 能正常校验。
   - **仅当该道具在 `bible/inventory.md` 确有对应行时**，才补 `- 物品：Ixxx`；原创短剧或仅短剧独有的道具不写 `物品`（乱填不存在的 I-ID 会触发 `va-item` 阻断），照常在 `visual/continuity.md` 里追踪连戏即可。
   - 凡条目画出了未收伏笔的作者真相，须在本阶段就填 `- 揭示伏笔：Fxxx` 或 `- 揭示集：N`，填完立刻刷新 `--brief`。
   - **本 skill 从不填写 `锁定词`，也不写参考图提示词或触发任何生图操作。**
2. **提示词阶段（`fiction-visual-prompts`）**：接手后补全完整视觉特征、`提示词称呼`、`声线`、挑选 `锁定词`，并在 `drama/{series}/prompts/assets-image.md` 编写资产参考图槽位与提示词（是否实际生成参考图由作者在下游另行决定）。

## 三、人物条目写法

- **必须用规范名**：`## 人物` 下的本体名必须与 `bible/characters.md` 的规范名一致，不用别名（否则 `storyboard-check.mjs` 报 `va-character`）。稳定特征与 `characters.md` 冲突时以 `characters.md` 为准（[SB §3](formats/project.md)）。
- **群演不建条目**：没有人物档案的路人、店客、围观人群不进 `assets.md`，直接写在分镜 `画面` 里。
- **只写画面看得见的词**：写“二十五岁上下，清瘦，短黑发微乱，眉骨平直，右手虎口一道发白旧疤”；不把“性格内敛、背负旧案”这类看不见的心理和背景抄进 `外观`。
- **正侧背都能认人**：尽量补一条从侧面或背面也能辨认的体型或发际线特征（如微驼肩、寸头、左耳垂缺口），方便背影镜和过肩镜认人。
- **阶段造型用变体**：常服、换装、淋湿脏污跨多集或跨场延续时建 `人物@造型名`（如 `林砚@灰布工装`）；仅维持一两镜的瞬时状态留在分镜 `画面` 里即可。

## 四、地点条目：3–5 个锚点与相对方位

地点条目的核心是**空间结构稳定**，确保正反打切机位时房间不会穿帮：

1. **每个地点定 3–5 个固定锚点**：用可选字段 `- 锚点：` 列出每次入画最该出现的固定陈设或实景光源。例如 `钟表铺`：
   - `- 锚点：柜台上的老式座钟、柜台左端的暖黄台灯、后墙木板缝、临街毛玻璃门`
   锚点太少容易每镜换房，超过 6 个则下游提示词顾此失彼。
2. **用相对方位，不用屏幕左右**：
   - **避免**在地点本体里写“画面左侧有一扇窗”“屏幕右边是后门”——正反打一换机位，画面左右全反。
   - **改为陈设之间的相对关系或固定朝向**：例如“木质修表柜台横在店铺当中，面向临街毛玻璃门；柜台内侧背后是通顶深色木板墙，暖黄台灯摆在柜台靠里门一端”。
3. **补一句人体尺度参照**：人物倚靠、撑桌、落座的家具写明相对人体的高度（如“木柜台高齐成年人腰间”），让画面比例稳定。
4. **门窗与固定家具不拆成道具**：柜台、毛玻璃门、路灯留在地点 `外观` 与 `锚点` 里，不单独列进 `## 道具`。

## 五、道具筛选与字迹处理五选一

### 哪些道具值得建条目

满足以下**任一条**才单建 `## 道具` 条目：

1. **需要特写辨认细节**（例如停在三点十分的 `座钟`、刻字的 `旧钥匙`）。
2. **跨场或跨集携带、转手、损坏或消耗**（需进 `visual/continuity.md` 追踪；若小说 `bible/inventory.md` 确有对应行再补 `- 物品：Ixxx`，没有则不填 `物品`）。
3. **牵涉伏笔或防剧透门槛**（需挂 `- 揭示伏笔：` 或 `- 揭示集：`）。
4. **在多镜中被人物反复上手操作**，画走样观众一眼穿帮。

**不建条目的情况**：仅台词提及从未入画的物件；只作背景陈设的普通桌椅灯具；一次性普通环境杂物（直接写在分镜 `画面`）。

### 道具字迹处理五选一

当道具表面带文字、刻字、数字、标签或屏幕内容时，在可选字段 `- 字迹：` 里选定一种方式，供下游写提示词时遵守：

| 方式 | 适用情形 | 钟表铺示例 |
| --- | --- | --- |
| **1. 清晰可读** | 剧情要求观众看清具体字样（写明精确原文，提醒下游提示词不可同时写“无文字”负面词） | `旧照片@背面`：右下角手写日期（须先过防剧透门槛） |
| **2. 只留版式轮廓** | 远看像有字或表格，不需读清内容（保留排版色块，不硬出可读字） | 柜台玻璃板下压着的泛黄修表价目单 |
| **3. 表面无字** | 器物保持素面干净，避免出图乱码 | 素色旧帆布工具袋 |
| **4. 字句待作者拍板** | 剧本只写“露出编号 / 品牌”，具体字样未定或涉现实商标（停下请作者定虚构字样或去标方案） | 涉事旧电机的铭牌字样 |
| **5. 仅后期叠加** | 手机弹窗、字幕条、精确跳字留待后期合成，画面对应区域保持留白 | 手机来电界面或电子倒计时 |

## 六、与下游锁定词的配合（本 skill 不写锁定词）

`锁定词`（[SB §9.4](formats/storyboard.md)）由下游 `fiction-visual-prompts` 统一挑选和维护，本 skill 不填写。但分镜阶段拆分变体时须提前考虑下游如何加锁：

- **服装与阶段状态拆到变体上**：例如把工装外套拆进 `林砚@灰布工装`，而不是混在本体 `林砚` 的 `外观` 里。这样下游把外套锁定词挂到变体上时，手部特写或换装镜头不引用该变体就不会误报缺锁。
- **涉密本体与遮挡变体分开**：变体默认继承本体全部字段。若为受门禁限制的本体建了 `- 揭示集：1` 的遮挡变体，须在交接说明里提醒 `fiction-visual-prompts`：切勿把带有泄底信息的 `锁定词` 留给该遮挡变体继承（必要时在遮挡变体上用空值 `- 锁定词：` 覆盖），也不要给早期镜头挂本体参考图。
- **下游挑选锁定词的基本口径（仅供交接参考）**：宁少勿多，只锁跨多镜反复出现且画偏易穿帮的核心静态名词短语（颜色 + 材质 / 款式 + 物件，不含动作与临时方位，中英双语用 `=` 连接）。
