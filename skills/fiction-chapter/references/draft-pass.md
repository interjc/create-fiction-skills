# 轻审与写作备忘

用于卡在具体场景、未装 `fiction-craft` 或未装 `fiction-review` 时。按本书已经确认的写法取舍，不借检查另定世界规则或剧情方向。

## 切场与投放信息

- [ ] 进场先让读者知道「人在哪、离上次过了多久、正在做什么」，不用逐刻交代。默认挑两种能影响判断或情绪的感官线索；下一场跳时就给新的锚点，不把赶路当转场正文。 [模型]
- [ ] 紧场用短句和连续动作；缓场把篇幅给人物的反应、互动和两难。要加速，缩短反应或让新冲突打断；要让代价落地，至少留一个反应和决定。章内应有一个可感到的小高点，如发现、转折或关系变化。 [模型]
- [ ] 守住本书授权视角：角色只判断自己能看到、听到或推断的事；不替别人猜完心理。写机敏、强势或窘迫，用判断、动作、站位、语气和旁人反应，不靠赞美或社会标签。 [模型]
- [ ] 暗线还不到揭晓点，只给可见异常与暂时说得通的表层解释，留下一个解释不了的细节。先确认本书允许换视角，才用极短的章末异地提示；不借镜头切换透露真相。 [模型]
- [ ] 伏笔初读时在当场也有用；回收时先用一件物或一个动作让读者想起旧场景，再给新解释。一般章集中兑现一两条就好，密集回收按卷纲，不用旁白罗列旧线索。 [模型]
- [ ] 信息分层：私下先给必要背景，正式场景只补执行所需；别人只说轮廓，当事人再补边界。同一句话不在对白、旁白和书中资料里讲三次。 [模型]

### 不展开完整技法时，先抓这一件事

| 场景任务 | 最小处理 |
| --- | --- |
| 准备章 | 先让人物处理一件手头事，用实际分工和实物证明准备完成；行动本身若是下一章职责，就收在动手前。 |
| 行动章 | 边走、边看、边做时交换判断；普通赶路略写，展开改变危险或配合方式的节点。每个人只补自己知道的一层。 |
| 收获盘点 | 优先写眼下能用、需处理才有用、暂时搁置的区别，让读者看见谁用它、它替换了什么、会改变下一步什么。 |
| 交易 | 贵重物件说清档次、用途、使用门槛和适用场合；整单议价就让价格随整单条件改变，不做单向商品介绍。 |
| 借文内资料讲设定 | 点出资料名 → 短摘一句 → 用角色熟悉的东西对照 → 回到眼下动作。资料不是课堂讲义。 |

若卷规划启用了题材包的「区域循环」，按卷规划自由区的本章记录，在章纲职责或场景安排内核对步次、新增区域理解和可见收益。缺技法参考时沿用已定分工，不另造模板或改变卷结构。

## 轻审：从发现问题到复核

先对照本章职责与上章结尾，再从读者角度通读稿件。标位置和具体问题；只有确认未冻结且获得改稿授权才修。复读改处及前后衔接，仍有明显问题就再改一轮；结构性改动回到单章写作流程。正文变动后重跑正文字数与 lint。轻审不代替深审，交稿时列出仍待做的检查。

- [ ] 逐段做**删除测试**：拿掉这段，读者对因果的理解、情绪、期待或风险感会变吗？都不变就删、压成一句，或让人物承担一个具体的新冲突；不要换一套词填回去。承担换气或人物塑造的细节可以留，但能指出它的作用。 [模型]
- [ ] 搜「说到底」「这意味着」「他终于明白了」「真正……的是」一类句尾。若动作、对白或即时判断已让读者看明白，删除作者的总结，不只是替换关键词。视角合法的判断若确实引出新决定则可留。 [模型]
- [ ] 读出对白：角色的声口和所知范围能否区分？连续对白之间的动作是否改变气氛或对方判断？少用笼统黑话；首次出现的专业名词已给白话解释，准确但不拖住场景。 [模型]
- [ ] 校对人名、物件归属、时间和承诺。书中界面、消息或文书若有专门用法，先标明信息载体，核对规则的触发条件、格式和能力边界；能让角色自己观察到的，不靠载体代替一切判断。 [模型]
- [ ] 现实映射按本书规则处理：内部可精确定位，正文按口径用相对时间和必要的模糊化；不露写作文件、路径和幕后编号。配置词表是否覆盖全部本书禁用项，不由脚本替作者决定。 [模型]
- [ ] 尾段有真实的情绪落点或未完行动，留得出下一章的接点；不要用预告替正文收尾。标题优先用事件、地点或动作，不先替读者定性。 [模型]

## 人工回写核对

以实际定稿为证据，逐条对照该章 `outline.md` 和 `bible/` 主写记录，补足扫描看不到的正文遗漏。若扫描不能运行，这张清单仍可用来找遗漏，但不能把人工核对当作机检通过。

- [ ] 埋：有对应伏笔记录，埋设章是本章且不是计划中；触：本章记在触及章，或就在本章回收；收：已回收，实际回收章为本章；弃：已放弃，有作者同意与理由。 [模型]
- [ ] 章纲引用的支线和伏笔记录都存在。支线有步骤才记该步实际章为本章；只触及不补步骤。 [模型]
- [ ] 主写记录也与正文相符：在场与提及、新关系或人物弧线、明暗线进展、物品变动、时间锚点及已定规则；没有变化的项目不造记录。 [模型]
