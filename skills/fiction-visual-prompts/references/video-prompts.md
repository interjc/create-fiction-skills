## 先排动作，再写切点

逐段读 `storyboards/ep{NNN}.md`，对照本集剧本、已选帧图和 `visual/assets.md`。一段对应一次生成，时长来自段内各镜相加。把段镜号、文件名和路径留在字段与工作说明里，围栏内只写模型要生成的画面和声音。[SB §9.6](formats/storyboard.md)、[SB §9.7](formats/prompts.md)

1. **算切点。** 从零累计各镜秒数，标出硬切等转场。只翻译已经定下来的镜序。遇到台词、停顿和动作放不进秒数，把具体镜段退回 `fiction-storyboard`。
2. **分清起点、原因和结果。** 写「按下侧键后，屏幕熄灭。手机收回右衣兜，手停在兜口」。下一镜从这个状态接。按 [SB §9.5](formats/storyboard.md) 对照人、衣服与道具的连戏。
3. **每镜一条路径。** 写机位从哪里起、朝哪动、以谁为目标、停在哪里。固定镜只交代机位及取景。分镜有切点时，下一镜的机位从切点开始生效。
4. **让图管外观。** 叙述用 `提示词称呼`，原台词里的姓名照留。已由挂图覆盖的资产写动作、朝向和相对位置即可，段内晚入画且无图覆盖的资产带上原字锁。整段带入一次 `画风`。对照揭示时机检查每张图、每镜和每个音效。[SB §9.4](formats/storyboard.md)、[SB §9.7](formats/prompts.md)、[SB §9.9](formats/storyboard.md)

## 挂首帧或首尾帧

在 [SB §9.7](formats/prompts.md) 的 `参考图` 字段中，`SH001` 指该集该镜的首帧，`SH001尾` 指它的尾帧。假设一段从第一镜开始，在第三镜结束，字段可以写 `参考图：SH001、SH003尾`。按字段顺序上传，并在选定的入口分别放进首帧、尾帧位置。只有首帧时挂第一张，末尾动作由正文交代。模型标记和输入角色按已核对的方言卡选，内部镜号只留在字段里。[SB §9.8](formats/prompts.md)

对照两个端点的画幅、机位、轴线、光向、握持手和动作状态。分镜有切点时，按切点解释构图变化。如果目标入口无法接住指定的切法，请作者换合适的方言，或让 `fiction-storyboard` 重新定段。先选定实际图片，确认能按顺序上传，再把下游块纳入生成批次。可先起草，但缺图要列为依赖。

## 对白、口型与三层声音

| 剧本和分镜里的行 | 在视频正文与后期交接里怎么处理 |
|---|---|
| 普通对白 | 在开口的那一镜用引号逐字复制台词，保留标点。声线、停顿、嘴何时张开在引号外描述。只让该发话者对口型。 |
| OS | 当内心声或分镜指定的画外声写。给出声线、起止时间与画内反应。当画内角色就是声源时，也写「人物闭口，内心声响起」，除非同一段另有明确的画内对白。 |
| VO | 用指定声源与听感区分来处，例如「听筒里有压低的男声，拿听筒的人闭口听」。需要原声就按已定时段写原词，后期配音则保留节拍并在交接中附原词。 |
| 旁白 | 写成独立于画中角色的声音。用起止时间对齐画面，画面按分镜交代表情或动作。后期录旁白就把原词和时间交给配音。 |
| 字幕 | 把原文与出现、消失时间留给后期字幕轨。画面提示只交代必要留白，字幕正文不作为画内字迹出图。 |

台词检查开启时，普通对白要原样包含在 `prompt` 中，OS、VO、`旁白`、`字幕` 是脚本检查的例外。作者确定后期配音时，按 [SB §8](formats/config.md) 用 `prompts.dialogue_check: false`，继续按原分镜安排开口或闭口、停顿与反应。[SB §9.7](formats/prompts.md)

- **人声**写谁、何时、在画内还是画外、声量及口型。
- **环境及动作声**写持续的空间底声，再给确有来源的事件音。柜台旁一直有街声，衣料摩擦只在手机压进兜时出现。删动作时同步删它触发的声响，以免提示词反向要求模型补演。
- **配乐**照分镜写什么时候进出、是否压低。定为无配乐时直接写「无配乐」。把音量安排与对白和关键动作声对一遍。[SB §9.6](formats/storyboard.md)

## 带切点的钟表铺示例

示例的资产和分镜片段均为本参考文档虚构，故事发生在钟表铺。唐七按灭手机并收回右衣兜，林砚问「怎么不接？」。示例从唐七已举起手机开始，止于问完。唐七接下来的回应归后续段。
这段三镜，累计切点为 2.5、5.5 秒，8.5 秒收尾。货运司机用唐七本体，锁「洗褪色的藏青冲锋衣」。修表匠用林砚本体，锁「深灰工装夹克」。玻璃柜台是守信钟表铺的锚点。手机没有锁，全剧 `画风` 为「写实、低饱和、自然光质感。」[SB §9.4–§9.6](formats/storyboard.md)

````markdown
- 对象：唐七
- 视图：正面全身
- 方言：generic
- 状态：草稿

```prompt
竖屏 9:16，全身。三十出头的货运司机正面站立，肤色偏深，左耳垂缺一小块，穿洗褪色的藏青冲锋衣。双臂自然垂下，头和鞋完整入画，浅灰纯背景，均匀柔光。写实、低饱和、自然光质感。
```

```negative
多人，多视图拼贴，视图标签
```
````

### 帧图 `prompts/ep001-image.md`

````markdown
# 第1集图片提示词

## SH004
- 帧：首帧
- 方言：generic
- 状态：草稿
- 参考图：REF001

```prompt
竖屏 9:16，近景。唐七沿用第一张参考图的脸和服装，站在玻璃柜台外侧，右手持手机在胸前，目光落在屏幕上，拇指悬在侧键旁。柜台边沿从画面左下切入，柜面略低于他的手肘，手机屏面斜向他，只露一线屏光。临街门口的漫射日光从右侧入画。写实、低饱和、自然光质感。
```

```negative
额外人物，玻璃里的人形倒影，画面边缘的贴字
```
````

帧图引用唐七的锚图，所以唐七的锁由挂图豁免。玻璃柜台交代唐七的站位和柜面的高度。这个起点留出清楚的拇指位置，供第一镜动作接上。

### 分段视频 `prompts/ep001-video.md`

````markdown
# 第1集视频提示词

## SEG02
- 方言：generic
- 状态：草稿
- 参考图：SH004

```prompt
白天，竖屏 9:16，临街钟表铺。写实、低饱和、自然光质感。
0–2.5 秒，近景。按首帧的站位开场。货运司机低头看着举在胸前的手机，右拇指按下侧键，屏光熄灭。镜头从柜台外侧沿直线轻推，停在手和下半张脸仍同框的位置。
2.5 秒硬切。2.5–5.5 秒，固定中景。从同一侧看过去，货运司机把屏幕已暗的手机压回右衣兜，手留在兜口，嘴唇闭合。
5.5 秒硬切。5.5–8.5 秒，固定近景。柜台里侧，穿深灰工装夹克的年轻修表匠抬眼望向对面，停半拍开口问“怎么不接？”说完闭口，视线留在对面。
人声：只有最后一镜的修表匠发声，音量轻，口型随问句起落。前两镜的司机保持闭口。
环境及动作声：远处街声贯穿两个切点，按键没有提示音。手机推入右衣兜时才有短促的布料摩擦声。
配乐：全段无配乐。
```
````

第一镜向前一小段，后两镜固定，各镜只有一个运镜要求。首帧所属镜头有唐七入画，因此该视频可省唐七的字面锁。修表匠只在第三镜入画，仍须保留「深灰工装夹克」。如果经作者确认另做首尾帧版，可在选定第三镜尾帧后用 `参考图：SH004、SH006尾`。届时按实际挂图重新判定锁，首尾帧版也要重新预览和确认。[SB §9.7](formats/prompts.md)

## 段落验收

按 `prompt-check.mjs --help` 的用法在书根跑本集检查。先处理结构、参考图和台词阻断，再复核全部建议。超长度先删重复外观、画外陈设和修饰，留下动作因果、切点、逐字台词、必要声源和仍生效的锁。若是段时长超过所选方言的上限，让作者选合适方言，或交回 `fiction-storyboard` 分段。[SB §9.6](formats/storyboard.md)、[SB §9.7–§9.8](formats/prompts.md)

沿实际秒数读一遍并看端点图。台词与动作挤在一起、朝向接不上或需要换切法时，交回具体段镜、原因和未验证事项。成片回填后再查文件路径，并请作者核对画面、口型和声音。[SB §9.7](formats/prompts.md)
