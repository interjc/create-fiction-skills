# 阿里云百炼 Wan 2.7：首帧／首尾帧

- 方言：wan-2.7-i2v
- 适用：视频
- 核对日期：2026-11-21
- 官方文档：https://www.alibabacloud.com/help/zh/model-studio/image-to-video-general-api-reference

以下限制以官方当前文档为准。只覆盖百炼万相 2.7 图生视频的首帧／首尾帧任务，不外推到早期版本、续写或独立角色参考模式。[SB §9.8](../formats/prompts.md)

| 项 | 本次核对 |
|---|---|
| `max_chars` | `5000`；正向支持中英文，超长会截断。另有不超过 500 字符的 `negative_prompt`，本地 `max_chars` 不检查负向字数。 |
| `max_seconds` | `15`；可选 2–15 的整数秒。 |
| `max_refs` | `2` 仅用于首尾帧；首帧任务只挂 `1` 张。音频不算图片张数，且不是提示词块的 `参考图`。 |
| `forbid` | 未核对，不预填。 |

用自然语言写动作、切点和声音，不把 `first_frame`、`last_frame` 类型标签混进正文；这些是平台侧媒体角色。文档说明可另用音频驱动口型，但未核对到自然语言台词的专用标记或逐字发声保证。若要保留提示词逐字意图，先让作者检查该入口的 `prompt_extend`（文档说明默认启用，可关闭），再验实际成片。720P／1080P 输出尽量沿用输入宽高比，不保证精确等比；以本集首帧核对成片画幅。
