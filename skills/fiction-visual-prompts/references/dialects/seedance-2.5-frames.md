# 火山方舟 Seedance 2.5：首帧／首尾帧

- 方言：seedance-2.5-frames
- 适用：视频
- 核对日期：2026-11-21
- 官方文档：https://www.volcengine.com/docs/82379/1520757

以下限制以官方当前文档为准。只覆盖火山方舟 Seedance 2.5（非 flash）的首帧或首尾帧模式，不外推到全模态参考、编辑、续写或其他入口。[SB §9.8](../formats/prompts.md)

| 项 | 本次核对 |
|---|---|
| `max_seconds` | `30`；`duration` 可填 4–30 的整数秒，也可用 `-1` 交由模型选择。脚本只提示超上限。 |
| `max_refs` | `2` 仅用于首尾帧；首帧模式只能用 `1` 张。两种共用一个方言时，`2` 只查总体上限，每块实际模式仍要人工核对。 |
| `max_chars` | 未核对，不预填。 |
| `forbid` | 未核对，不预填。 |

用 `first_frame` 指定首帧、`last_frame` 指定尾帧。把这两个角色设置在媒体输入里。使用 `ratio: adaptive` 时画幅跟随首帧，先核对首帧的实际比例。独立负面词参数未核对。
