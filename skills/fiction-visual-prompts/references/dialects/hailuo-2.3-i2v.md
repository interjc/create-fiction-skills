# MiniMax 海螺 2.3：首帧生视频

- 方言：hailuo-2.3-i2v
- 适用：视频
- 核对日期：2026-11-21
- 官方文档：https://platform.minimax.io/docs/api-reference/video-generation-i2v

以下限制以官方当前文档为准。只覆盖 MiniMax 官方 API 的 `MiniMax-Hailuo-2.3` 首帧入口；不外推到海螺网页端或其他版本。[SB §9.8](../formats/prompts.md)

| 项 | 本次核对 |
|---|---|
| `max_chars` | `2000`；官方提示词字符上限，本地以契约码点算法作近似提示。 |
| `max_seconds` | `10`；768P 只可选 6 或 10 秒，1080P 只可选 6 秒。只做 1080P 的项目应核对 `6`。 |
| `max_refs` | `1`；本入口只接一张起始帧 `first_frame_image`，不能把尾帧或人物拼板再塞进来。 |
| `forbid` | 未核对，不预填。 |

自然语言可描述运镜；该版本也支持方括号运镜指令。例如分镜确定缓慢前推，可用 `[Push in]`，不要再叠加一个反向移动。固定机位可用 `[Static shot]`。先对照分镜时长与输出档位，不把「不超过 10 秒」误读成「任意秒数都能填」。文档未核对到台词标记、原生有声能力或独立负面词参数；不要承诺逐字配音，也不要借用其他版本的标签。若打算后期配音，请作者先确定方案。

需要保留提示词与锁定词的原字时，请作者核对实际入口的 `prompt_optimizer`。官方 API 默认 `true`，会改写提示词，可设为 `false` 关闭改写。成片仍要逐镜核对。
