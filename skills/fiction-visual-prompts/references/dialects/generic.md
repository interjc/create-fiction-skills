# 通用方言 `generic`

- 方言：generic
- 适用：视频
- 核对日期：2026-11-21
- 官方文档：-

以下限制以官方当前文档为准。本卡是套件自身的基线，没有厂商文档或厂商限制。「适用」表头按 [SB §9.8](../formats/prompts.md) 登记为视频；未指定厂商时，图片同样可用 `generic` 的自然语言写法。

- **视频**：按「画面内容 → 动作先后 → 运镜 → 声音」直写自然语言；实际台词用引号原样写出，不加模型专用标签。例如：「修表匠站在柜台后，抬眼看向门边，开口问：『怎么不接？』镜头固定。铺里只有轻微的街声，无配乐。」
- **图片**：同样不用专用标记；写一个可定格的瞬间，识别参考图时用「第一张参考图」一类自然语言，把作品内部编号留在字段区。[SB §9.7](../formats/prompts.md)
- **限制**：不提供 `max_chars`、`max_seconds`、`max_refs` 或 `forbid` 的厂商值。仍按 [SB §8](../formats/config.md) 的项目提示线检查；该提示线不是模型上限。
