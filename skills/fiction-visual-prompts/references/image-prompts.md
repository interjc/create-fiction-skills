## 补视觉资产

按 [SB §9.4–§9.5](formats/storyboard.md) 把同一对象拆成三层。先在 `visual/assets.md` 填稳定的可见外观和能画出来的 `提示词称呼`，如「年轻修表匠」。再用变体记录换装、损坏等阶段状态。变体继承本体字段，写了同名字段便覆盖。最后从分镜读这一镜的手势、站位和道具位置，把它们留在帧图里。

锁定词选少量跨镜反复可见的静态名词短语。颜色、材质和物件可一起锁，比如「洗褪色的藏青冲锋衣」。一把锁用两种语言时以 `=` 连接。未挂图的块按 [SB §9.7](formats/prompts.md) 在正向围栏里原字写出其中一种。脚本按约定的字面和挂图关系判断，实际画出哪一件衣服要对着图验。

地点不加锁定词：地点靠 `锚点` 与参考图保持一致；§9.7 按段给每一镜派生地点，地点带锁会让同段每个特写都收到 `pr-lock`。只露手的特写照常保留分镜的 `人物`，对没入画的外套给的 `pr-lock` 建议照留，在汇报里写「手部特写，外套不入画，保留」，不要为消建议往提示词里塞画外的衣服。

## 选参考图并建立依赖

在 `prompts/assets-image.md` 建需要的块，先读 [SB §6.1](formats/prompts.md)、[SB §9.7](formats/prompts.md)。

| 对象 | 提示词怎样写 | 出图后怎样验 |
|---|---|---|
| 人物 | 先出正面全身单人锚图，脸、头发、衣领和鞋都在框内。选定后只挂同一张锚，分别派生正脸大头、侧面、背面，每次只改视角或取景。 | 并排看脸型、发际线、体型、衣领和鞋。身份偏了先换派生图，已有锚图继续给其他视图使用。 |
| 地点 | 出无人空景。用门、柜台、窗等固定陈设说明方向及距离，按镜头实际取景留下看得到的锚点。 | 以进门方向校对柜台与窗的相对位置，给反打保留可辨的空间线索。 |
| 道具 | 单物白底，带尺或其他清楚的尺度参照，画面无手。正背面或开闭状态各出单图。 | 比对尺寸、材料、磨损和该露出的字。对有揭示门槛的道具，核对图里是否露出未到时机的一面。 |
| 外部图片 | 作者确认采用后填 `来源：外部`，按所选图登记 `文件` 和状态，可省略生成围栏。 | 核实文件、使用权、所示造型和本集可见范围。 |

派生图和帧图可以先写草稿。实际出图前，核对引用的块、文件和造型，然后按 `参考图` 的列出顺序挂图。REF 块只引用 REF。帧图挂了该角色的对应图，正文才按需直接叫姓名。只挂其他资产图时，仍以这个角色的 `提示词称呼` 描述他。REF 挂图豁免按资产本名判断，手工须对照连戏核对变体和揭示时机。[SB §9.5](formats/storyboard.md)、[SB §9.7](formats/prompts.md)、[SB §9.9](formats/storyboard.md)

## 从分镜定格一帧

1. 先写画幅、景别。取本剧 `画幅` 或项目默认画幅，景别从该镜读，写清框中可见的身体或物件范围。[SB §8](formats/config.md)、[SB §9.4–§9.6](formats/storyboard.md)
2. 接着写挂图与主体、这一帧的姿态和目光。用「拇指悬在侧键旁」定格按键前一瞬。尾帧有明确用途才单列一个块，写动作完成后的位置和姿态。
3. 加上必要的空间与尺度，再交代光从何处来，把 `画风` 整句带入。按分镜定方向，描写观众能看见的固定锚点。[SB §9.4](formats/storyboard.md)
4. 用定向负面词去掉本图容易多生的东西。道具上有必读文字时，正向交代字样、朝向、光和可读区域。负向只排除画外的字幕、水印和多余标签。若字迹此镜还不可见，写实际遮挡方式，正负围栏都只交代当前可见的信息。[SB §9.7](formats/prompts.md)、[SB §9.9](formats/storyboard.md)

## 钟表铺的资产图、帧图和视频段示例

示例的资产和分镜片段均为本参考文档虚构，故事发生在钟表铺。唐七按灭手机并收回右衣兜，林砚问「怎么不接？」。示例从唐七已举起手机开始，止于问完。唐七接下来的回应归后续段。
按 [SB §9.4–§9.6](formats/storyboard.md)，示例用唐七本体，锁「洗褪色的藏青冲锋衣」。林砚本体锁「深灰工装夹克」。玻璃柜台是守信钟表铺的锚点。手机没有锁，剧的 `画风` 是「写实、低饱和、自然光质感。」分镜三镜的时长依次为 2.5、3、3 秒，唐七在前两镜，林砚在第三镜。

### 资产参考图 `prompts/assets-image.md`

````markdown
# 资产参考图

## REF001
- 对象：唐七
- 视图：正面全身
- 方言：generic
- 状态：草稿

```prompt
竖屏 9:16，全身。三十出头的货运司机正面站立，肤色偏深，左耳垂缺一小块，穿洗褪色的藏青冲锋衣。双臂自然垂下，头和鞋完整入画，浅灰纯背景，均匀柔光。写实、低饱和、自然光质感。
```

```negative
多人，多视图拼贴，视图标签
```
````

锚图先以草稿交付。没有挂图，衣着锁原字写入，正文用「货运司机」。作者选定并产出后再回填实际文件。

### 帧图 `prompts/ep001-image.md`

````markdown
# 第1集图片提示词

## SH004
- 帧：首帧
- 方言：generic
- 状态：草稿
- 参考图：REF001

```prompt
竖屏 9:16，近景。唐七沿用第一张参考图的脸和服装，站在玻璃柜台外侧，右手持手机在胸前，目光落在屏幕上，拇指悬在侧键旁。柜台边沿从画面左下切入，柜面略低于他的手肘，手机屏面斜向他，只露一线屏光。临街门口的漫射日光从右侧入画。写实、低饱和、自然光质感。
```

```negative
额外人物，玻璃里的人形倒影，画面边缘的贴字
```
````

这帧只画按灭前一瞬。唐七挂同名 REF，可省掉冲锋衣锁的原字并用姓名。玻璃柜台交代唐七的站位和柜面的高度。此镜的屏面朝内，正文只写一线屏光。

### 分段视频 `prompts/ep001-video.md`

````markdown
# 第1集视频提示词

## SEG02
- 方言：generic
- 状态：草稿
- 参考图：SH004

```prompt
白天，竖屏 9:16，临街钟表铺。写实、低饱和、自然光质感。
0–2.5 秒，近景。按首帧的站位开场。货运司机低头看着举在胸前的手机，右拇指按下侧键，屏光熄灭。镜头从柜台外侧沿直线轻推，停在手和下半张脸仍同框的位置。
2.5 秒硬切。2.5–5.5 秒，固定中景。从同一侧看过去，货运司机把屏幕已暗的手机压回右衣兜，手留在兜口，嘴唇闭合。
5.5 秒硬切。5.5–8.5 秒，固定近景。柜台里侧，穿深灰工装夹克的年轻修表匠抬眼望向对面，停半拍开口问“怎么不接？”说完闭口，视线留在对面。
人声：只有最后一镜的修表匠发声，音量轻，口型随问句起落。前两镜的司机保持闭口。
环境及动作声：远处街声贯穿两个切点，按键没有提示音。手机推入右衣兜时才有短促的布料摩擦声。
配乐：全段无配乐。
```
````

按 [SB §9.7](formats/prompts.md)，视频挂首帧，可省该帧所属镜头中唐七的外观锁。林砚到第三镜才入画，保留「深灰工装夹克」。第一镜只有一条直推路径，后两镜固定。2.5 秒和 5.5 秒切换。台词保留原标点，人声、声景、配乐各有安排。

## 出图后核对

在书根运行 `node <本 skill 目录>/scripts/prompt-check.mjs <series> --ep N`，看结构、引用、锁词、长度及已出文件路径。超长度提示线时，先剪掉画外陈设、同义修饰和重复的挂图信息。确认图确实生成后按 [SB §9.7](formats/prompts.md) 回填，再跑检查。另用眼睛核对身份、服装、方向、屏光和字迹。

若需要换景别才能读出关键字，或发现分镜要求的造型、站位与连戏相冲突，把镜头、问题和未完成的帧图交回 `fiction-storyboard`。分镜更新后重查受影响的帧图和视频块。[SB §9.5–§9.6](formats/storyboard.md)
