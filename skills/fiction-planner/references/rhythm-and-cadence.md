## 一、爽点节拍与外部打断

节奏参数统一从 `.fiction/config.json` 读取（[SB §8](formats/config.md)）；下文凡出现具体章数，均明确标出是默认值或默认示例，项目有自定义配置时以配置为准。

### 1.1 爽点节拍（`rhythm.beat_every`，默认 `[3, 5]`）

按项目配置的 `rhythm.beat_every`（默认为每 **3–5 章**）至少落地一个明确爽点（让读者获得情绪释放、好奇满足或成就感的强节点）。在 `bible/volumes/{vol}.md` 的 `## 章节规划` 表（[SB §7.5](formats/chapter.md)）中，把爽点显式填进 `爽点` 列，并轮换类型，避免连续重复同一套路导致疲劳：

| 爽点类型 | 核心机制 | 规划示例（原创） |
|---|---|---|
| **发现型** | 查出别人没看出来的隐秘规律或实物线索 | 从旧表芯刻痕发现停表时间是人为定格 |
| **突破 / 成长型** | 能力、技艺、资源或身份迈过清晰门槛 | 首次独立复原失传擒纵结构，拿到行内认可 |
| **智力 / 破局型** | 用信息差、规矩漏洞或巧妙布局反制难题 | 借旧铺租赁条款反将催债人一军，合法拖出窗口期 |
| **情感 / 关系型** | 信任建立、误会冰释、护短或暗中照应落地 | 嘴硬的葛婶悄悄替林砚挡下街口打听消息的人 |
| **悬念 / 揭秘型** | 揭开一层旧伏笔，同时打开更大格局 | 闸房旧日志里赫然出现父亲的签字 |
| **反杀 / 展现实力型** | 前期被轻视后，在关键场合亮出硬本事 | 面对行家当众刁难，三分钟听声定位暗病 |
| **兑现 / 成就回馈型** | 前期投入、目标或伏笔迎来实打实的资源/名声回报 | 修复稀缺古钟拿到保住铺子的首笔大款，顺手补齐紧缺工具 |
| **外部冲击型** | 主角的动作在外界炸出回响或引发格局异动 | 河道旧案重新被提起，各方人马开始往老街聚拢 |

> 若已安装 `fiction-craft` 且配置了 `book.genres`，优先对照对应题材包里的细分爽点类型补充本表。

### 1.2 外部打断上限（`rhythm.external_event_max_gap`，默认 `2`）

- 无论这几章在写闭门钻研、材料准备、日常相处还是内部推演，**连续无外部事件的章数**不得超过 `rhythm.external_event_max_gap`（默认最多连续 `2` 章）。
- 下一章（按默认配置即第 `3` 章）必须插入外部事件打断：外部访客、突发危机、支线节点撞上门、第三方消息或环境异变。
- 规划时顺手压缩“顺利但无增量”的过渡段（普通赶路、例行寒暄、重复准备）：如果一章既不增加信息、不推进情绪、也不抬升风险，就与前后章合并，不要单占一章。

## 二、欲扬先抑（微观 / 中观 / 宏观）

欲扬先抑的核心是“先压低、再抬高”——前面的压迫或轻视越具体，后面的反转落差越大，爽感越强。

**基本公式**：`低姿态 / 被轻视 / 受挫 → 克制承接、不动声色或暗中积累 → 关键时刻凭真实积累反转 → 读者爽感释放`

### 三层级排布

| 层级 | 跨度 | 排布方式 | 原创示例 |
|---|---|---|---|
| **微观** | 单章单场 | 场景前半被刁难或看轻，后半用具体动作当场折服 | 客人质疑年轻师傅修不了老怀表，林砚不辩解，听两声嘀嗒直接报出十年前换过的游丝尺寸 |
| **中观** | 跨 3–5 章（小弧线） | 前两章被压制或吃闷亏，中间暗中补齐短板，第 4–5 章正面翻盘 | 第 11–12 章铺子被断货刁难 → 第 13 章连夜盘清旧零件库并找葛婶牵线 → 第 14 章准时交货反抢回大单 |
| **宏观** | 跨卷 | 前卷处于底层、信息盲区或弱势，历经积累后在后卷完成身份与话语权逆转 | 卷 1 守着破铺勉强糊口、处处被蒙在鼓里 → 卷 2–3 摸清河道旧网 → 卷 4 成为多方不得不来登门请教的关键人物 |

### 三条禁忌

1. **不能只有“扬”没有“抑”**：没有低谷垫高，再大的成就也缺乏冲击力。
2. **“抑”必须真实、具体、可共情**：不能为了压而把主角写得愚蠢窝囊，也不能敷衍一句“他受了委屈”就草草跳过。
3. **反转必须来自前置积累**：破局底牌要在前文埋过能力、物品或人脉，不能临时天降外挂。

## 三、冲突升级阶梯

规划整卷或多章冲突弧线时，遵守“冲突只能往上走，不能无故往回退”的原则。

### 八级阶梯

`① 平静 → ② 障碍 → ③ 误解 → ④ 困境 → ⑤ 紧张 → ⑥ 危机 → ⑦ 绝境 → ⑧ 反杀 / 收束`

### 使用规则

- **允许跳级**：节奏紧张时可从 ② 直接跳到 ⑤。
- **绝不逆行**：冲突推进到 ⑤ 后，不能无故退回 ③，除非开启一条新的冲突线。
- **对抗必须双向**：双方持续过招，主角每出一步招，对手或环境必须给出合理反制，避免单方面吊打。
- **落差决定精彩度**：⑦（绝境）压得越实，⑧（反杀/收束）的释放越强烈。

### 四类冲突配比（卷纲内注意搭配，避免单调）

- **人 vs 人**：利益争夺、信息博弈、立场对撞（靠对话与行动呈现，不贴脸谱化标签）。
- **人 vs 自然 / 环境**：恶劣天气、物理极限、失控现场、时间倒计时（靠具象感官与硬限制施压）。
- **人 vs 系统 / 规则**：行业门槛、制度规程、阶层壁垒、隐性潜规则（靠冷峻现实反差施压）。
- **人 vs 自我**：信任与怀疑、止损与冒险、旧伤与责任（内心挣扎忌冗长，用具体决定与行动收束）。

## 四、情绪波形设计

### 4.1 波浪原则与三条铁律

理想卷内情绪走势：`小起伏 → 阶段高潮 → 低谷消化 → 更高高潮 → 喘息收束 → 卷末最高峰`

1. **绝不连续两章同为高潮或同为低谷**：连炸两章会审美疲劳，连水两章会直接掉追读；紧后必有松，松后要更紧。
2. **后一弧线峰值高于前一弧线**：整卷的权重分布（`轻` / `中` / `重`）应呈阶梯式抬升，把最重的戏压在卷中后段与卷末高潮。
3. **低谷不是“无事发生”**：喘息章（`权重：轻`）必须承担至少一项实务——放三层涟漪、推进 B/C 级支线、深化人物关系、盘点升级收益，或种下下一弧线与下一卷的大钩子种子。

### 4.2 完整情绪周期

每个中弧线（6–12 章）或整卷，尽量走完一条完整情绪曲线：
`好奇 → 期待 → 紧张 → 恐惧 / 绝望 → 转折 → 释放 / 满足`

## 五、章末钩子分级与日更 / 爆更分组

钩子标记语法与 S/A/B/C 四级定义见 [SB §7.2](formats/chapter.md)，规划阶段把计划级别直接写入 `bible/volumes/{vol}.md` 的 `钩子` 列（[SB §7.5](formats/chapter.md)）。

### 5.1 钩子选型参考

| 级别 | 定位 | 规划用法 | 原创示例 |
|---|---|---|---|
| **S** | 重大反转 / 生死危机 / 核心身份揭穿 | 卷高潮、黄金三章收口、爆更期每日末章 | 闸房铁门从外面被反锁，水阀开始自动泄水 |
| **A** | 新信息揭露 / 悬念加深 / 强冲突将起 | 日常更新每日末章默认下限 | 烟盒内衬夹着林砚父亲失踪前一夜的签字值班表 |
| **B** | 情绪转折 / 做出决定 / 关系变化 | 日更非末章、弧线过渡章 | 林砚收起钥匙，决定当晚独自去河堤探一眼 |
| **C** | 平静收束 | **写作建议**：尽量避免，仅限大高潮后的喘息章 | 天亮回到铺子，给座钟重新上满发条 |

> **区分写作建议与机检配置**：上面“仅限大高潮后喘息章”是针对 `C` 级的写作建议；而 `.fiction/config.json` 中的 `hook.discouraged`（默认 `["C"]`，[SB §8](formats/config.md)）是机检提示列表——若项目把其他级别（如 `B`）也加入了 `hook.discouraged`，规划时按配置复核并提示作者。

### 5.2 日更分组与爆更期编排（含交接落点）

读取 `.fiction/config.json` 的 `daily.*` 参数（[SB §8](formats/config.md)），按“发布日”对卷规划表分组复核，**并在 `bible/volumes/{vol}.md` 自由区写明 `## 日更 / 爆更分组备注`**，供 `fiction-chapter` 填入单章 `outline.md` 的 `## 日更位置`（[SB §7.3](formats/chapter.md)）：

1. **日常更新**（默认示例：`daily.chapters_per_day = 2`，`daily.last_hook_min = "A"`）：
   - 按配置章数分组（按默认每 2 章一组，如第 11–12 章、第 13–14 章）；
   - 非末章常用 `B`（铺垫/转折/小爽点）或更高级别；
   - **每日末章计划钩子不低于 `daily.last_hook_min`**（默认下限为 `A`，即 `A` 或 `S`），保证读者当天看完有明确追更动力。
2. **爆更期 / 推荐期**（默认示例：`daily.burst.chapters_per_day = [3, 5]`，`daily.burst.last_hook_min = "S"`）：
   - 当新书进入推荐、上架或集中加更窗口时，按配置的每日章数排成 **“爽点 → 喘息/铺垫 → 更大爽点”** 的波浪，切忌连续平推或全天打架；
   - 示例（单日 4 章波浪，仅作默认配置参考）：第 1 章（B/A，冲突起势）→ 第 2 章（A，小爽点/阶段反转）→ 第 3 章（B，涟漪消化+危机逼近）→ 第 4 章（**S**，大反转或生死悬念收尾）；
   - **每日末章计划钩子不低于 `daily.burst.last_hook_min`**（默认下限为 `S`）。

> 若作者自定义了日更章数或钩子下限（如日更 1 章或日更 3 章），严格按 `.fiction/config.json` 的 `daily.*` 分组复核，不硬套默认 2 章。

## 六、卷级规划落盘与更新顺序

规划方案经**作者确认后**，严格按 [SB §4.2](formats/project.md) 的主写入口顺序同步落盘：

1. **先改 `bible/volumes/{vol}.md`**（主写入口，格式见 [SB §7.5](formats/chapter.md)）：
   - 更新字段行 `- 章节范围：N-M`；
   - 在自由区写清本卷分段、情绪波形、人物与势力配置、`## 日更 / 爆更分组备注`（以及 `## 区域循环逐章备注`，若适用）；
   - 补全 `## 章节规划` 契约八列表（`章 | 核心事件 | 爽点 | 钩子 | 支线 | 伏笔 | 人物 | 权重`）。
2. **再同步 `bible/plot-outline.md`**：
   - 更新全书分卷总表中该卷的章节范围、核心主线与卷级大钩子，确保前后卷无缝衔接。
3. **最后更新 `chapters/{vol}/vol-info.md`**（次级摘要，格式见 [SB §7.4](formats/chapter.md)）：
   - 同步卷名、章节范围、卷级主线、详细规划路径与正文状态，**不在 `vol-info.md` 里复制整张章节规划表**。格式示例：

```markdown
# 第1卷：停摆的钟

- 卷名：停摆的钟
- 章节范围：1-20
- 卷级主线：接手旧铺、摸清停表异样与闸房旧案入口
- 详细规划：bible/volumes/1.md
- 正文状态：规划中
```

**禁止反向同步**：若发现 `vol-info.md` 或某章旧 `outline.md` 与 `bible/volumes/{vol}.md` 冲突，以 `bible/volumes/{vol}.md` 为准（[SB §3](formats/project.md)），修正次级文件后再开始写正文。
