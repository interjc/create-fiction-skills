## 九、一段话 30 秒自检清单

写完或改完一段，快速核对：

- [ ] **能不能更短？** 删掉无增量修饰和复述 `[模型]`
- [ ] **名词够具体吗？** 把泛称换成具体物件与空间坐标 `[模型]`
- [ ] **情绪落在动作里了吗？** 未违背本书情绪表达口径 `[模型]`
- [ ] **删掉这段有损失吗？** 不影响信息、关系或情绪体验即删或并 `[模型]`
- [ ] **对话超过约定句数了吗？** 超过即补动作、视线或环境声 `[模型]`
- [ ] **有双层解释或作者总结吗？** 人物已做出来的意思不再由旁白复述 `[模型]`
- [ ] **字面禁词、脱敏词、精确年份与内部编号是否清空？** 交 `fiction-review` 跑 `lint.mjs` 扫描 `[脚本]`
- [ ] **整体语感是否贴合基准样段、特殊禁忌是否需要增删？** 由作者最终拍板 `[作者]`
