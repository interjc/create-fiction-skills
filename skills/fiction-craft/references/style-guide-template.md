## 一、为什么每本书都要有自己的风格指南

通用技法解决“怎么写才好看”，而 `bible/style-guide.md` 解决“**怎么保证写到第三百章，读起来还是同一本书、同一个人写的**”。

- 它是项目级主写入口（登记在 `bible/sources.md` 的 `style_guide` 行，见 [SB §5](formats/project.md)），地位低于项目 `AGENTS.md`「本书口径」，高于本 skill 的通用默认（见 [SB §3](formats/project.md)）。
- 里面只放**本书的叙述声音、句式习惯、标点偏好、禁用表达与作者选定的样段**，不把通用写作教材整篇抄进去。
- 空白骨架见本 skill 的 `assets/style-guide.template.md`；新建时直接复制并填入本书口径。

## 二、必须定义的七个核心维度

一份真正能用来校准文风的 `bible/style-guide.md`，不能只写“文笔简洁、节奏明快”这种空词，必须把下面七个维度落成可判断的标准（外加叙事视角与禁止清单）：

| # | 维度 | 要定清楚什么（给可核对的口径，不给虚词） |
|---|---|---|
| 1 | **句长与段落节奏** | 日常段落与紧张段落各自的句长区间、单段行数上限，以及偏好的长短句交错节拍（全部由本书风格决定）。 |
| 2 | **标志性标点** | 本书最依赖的节奏标点及其分工（例如破折号、省略号、感叹号、分号的允许场合与频率上限，以及弯引号或直角引号约定）。 |
| 3 | **单句成段习惯** | 什么场合允许单句独占一段（如关键揭示、时间跳跃、情绪落点、幽默收尾），以及连续上限（避免通篇碎片化）。 |
| 4 | **对话习惯** | 单句平均长度、是否省去“焦急地说/冷冷道”类副词修饰、每几句插一次动作（默认 2–3 句）、整体口语化还是书面化程度。 |
| 5 | **幽默剂量与类型** | 本书要不要幽默？频率多高？属于哪种（冷幽默自嘲、日常吐槽、荒诞反差、还是严肃零搞笑）？绝对不碰哪类段子（如过时网络梗）。 |
| 6 | **禁用表达与雷区** | 本书明确禁止的腔调、套话与作者个人细项禁忌（如紫色散文、题材陈词、情绪直陈标签、作者总结句、是否避免在正文精确数出“这几个字”以防改稿错数，以及 emoji/颜文字；特殊禁忌一律由作者确认后写入）。 |
| 7 | **作者自选样段与样章路径** | 2–4 段**由作者本人选定**的本书基准片段（建议覆盖开场/动作、对话、日常/氛围、结尾），附一句“好在哪里”的标注，并记下对应的**样章文件路径**（`chapters/{vol}/{ch}/v{n}.md`）。绝不从别人的书里照抄样段。 |

补充两项必配基础设置：
- **叙事视角与叙述者距离**：锁定第一人称还是第三人称有限视角；叙述者紧贴主角还是略带旁观冷静感；允许切换视角的唯一条件（如章末暗线远焦）。
- **一段话速查清单**：浓缩成 5–7 个动笔或改稿前能 30 秒扫完的自检问题，每条标注责任方（`[脚本]` / `[模型]` / `[作者]`）。

## 三、两条构建路径：空书新建 vs 样章反向抽取

### 路径 A：作者已有 ≥2–3 章满意正文（推荐：反向抽取）

与其凭空想象想要什么文风，不如直接从作者写得最顺手的章节里抽取真实指纹：

1. **选样**：请作者指定 2–3 章最接近理想质感的章节（最好同时包含一场日常对话和一场紧张冲突）。
2. **量化观察（只读不改原稿）**：
   - 统计常见句长和段落行数，看开场第一句和章末最后一句的习惯写法；
   - 统计破折号、省略号、感叹号、分号的出现频率与用法；
   - 数一下单句成段的密度与出现位置；
   - 看连续对话通常几句插一次动作，有没有用对话副词；
   - 记下比喻通常取材自哪个生活或专业领域；
   - 标出作者反复避开的写法，以及样章里偶尔冒头、作者自己也不喜欢的习惯词。
3. **挑样段候选并记路径**：从样章中挑出 2–4 段最有辨识度的原句（每段 3–6 行），写清示范要点，并附上来源样章路径（`chapters/{vol}/{ch}/v{n}.md`）。
4. **交作者确认并登记**：把整理好的 `bible/style-guide.md` 草案呈现给作者，逐项确认“哪些是有意坚持的风格，哪些只是当时顺手写出来的巧合”。定稿落盘后，提醒作者把确认的基准样章路径同步登记到项目 `AGENTS.md`「本书口径」，供 `fiction-review` 直接对照校准。

### 路径 B：新书尚未动笔（问答共定）

1. **一轮精简问答**：围绕七个维度一次问清（每次给 2–3 个具体选项让作者拍板，比如“对话偏极简短来回，还是偏有来有回的生活闲聊？”“幽默偏冷幽默自嘲、轻松吐槽，还是基本严肃？”）。
2. **生成初版草案**：用 `assets/style-guide.template.md` 填入作者确认的条款；“作者自选样段与样章路径”一节先留空位，标注“待第 1–3 章定稿后补入”。
3. **三章后二次校准**：等黄金三章或首批满意章节写完后，按路径 A 回抽一次真实样段与样章路径，并微调条款，让指南从“设想”变成“实证”。

## 四、如何与审校（`fiction-review`）和机检联动

`bible/style-guide.md` 里的规则按“可确定性扫描”与“需阅读判断”分两层接入日常写作和审校闭环（`lint.mjs` 完整参数与模式语法见 `fiction-review`（或 `fiction-chapter`、`fiction-init`）附带的 `lint.mjs --help`）：

1. **字面禁词与脱敏词表 → `.fiction/config.json` `[脚本]`**：
   - 本书明确禁用的具体字面词条（字符串或 `{term, hint}`）→ 写入 `lint.banned_terms`（默认级别 `block`，命中报阻断）；
   - 现实地名/校名/公司名/人名脱敏词表 → 写入 `lint.desensitize.*`（默认级别 `block`，命中报阻断）。
2. **自定义句式、正则与内置模式开关 → `.fiction/lint-patterns.txt` `[脚本]`**：
   - 使用合法段头 `[summary:block]` / `[summary:suggest]`、`[ai-tone:block]` / `[ai-tone:suggest]`、`[custom:block]` / `[custom:suggest]`（可按需附加范围 `:narration` 或 `:all`）；正则以 `re:` 开头，可选 `=> 提示语`；关闭误伤本书风格的内置模式 ID 写入 `[disable]` 段：
     ```text
     [summary:suggest]
     总之一句话 => 删掉总结，让事实自己说话
     [custom:block:all]
     re:某本书禁用的固定句式 => 改写为具体动作
     [disable]
     AT23
     ```
   - 明确级别边界：`block` 级别由 `fiction-review` 运行 `lint.mjs` 报阻断（未改或未豁免则不通过）；`suggest` 级别仅报提示（不自动阻断，交由模型与作者逐条取舍）。
3. **声音贴合度与同义跑偏 → 对照 `bible/style-guide.md` 与基准样章 `[模型]` / `[作者]`**：
   - 句长疏密、单句成段是否过度、对白声音是否贴合人物、幽默剂量是否过火、比喻取材是否跑偏，脚本无法判定。
   - `fiction-chapter` 动笔前读 `bible/style-guide.md` 对齐手感；`fiction-review` 审校时按 `bible/style-guide.md` 与项目 `AGENTS.md`「本书口径」登记的基准样章路径对照复核。

## 五、校准与迭代时机

不要每写一章就推翻风格指南，但在以下四个节点应回看并微调：

1. **首批 3–5 章定稿后**：补入真实的作者自选样段与基准样章路径，删掉写起来别扭的纸上条款。
2. **发现反复被改掉的口癖或腔调时**：新增进“禁用表达”，并决定是否同步到 `lint.banned_terms` 或 `.fiction/lint-patterns.txt`。
3. **新卷切换大基调或启用新题材混搭时**：补充该阶段的局部口径（不要删除全书底色）。
4. **整卷复盘（`summary.md`）后**：对照读感最稳的一两章，检查风格是否出现悄然漂移。
