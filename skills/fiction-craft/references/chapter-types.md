## 一、准备章 / 集合章（六步剧本）

当本章职责是“出发前准备”“队伍集合”“交代规矩”“行动前夜”时，最容易写成一个屋子坐满人开说明会。按下面六步排布，把“说明”拆成“事情一件件落实”：

1. **先处理一件具体的手头事**：用实在动作开场——修工具、配药、装包、查路线、把关键物件试一遍。绝不一开头就拉人开会，也不先倒背景设定。
2. **把背景信息塞进自然小场景**：借赶路车上闲聊、茶摊碰头、群消息、递图时随口一问，放出“大概背景”（谁最近有长进、谁擅长什么、这趟风声如何）。只讲轮廓，不讲死细则。
3. **人到齐后只讲执行层**：真正碰头集合时，不再复述刚才聊过的背景，直接落到执行信息：
   - 站位与先后顺序；
   - 明确分工；
   - 联络方式与紧急信号；
   - 触发撤退或改变方案的条件。
4. **让当事人自己补能力边界**：带队人只压总体框架；具体到每个专业人员，由本人开口补齐“我能做到哪一步、你们怎么配合、什么情况下往我这边靠”。既自然立人设，又避免旁人替他吹嘘或复读。
5. **用实物把准备落地**：让物件过手——对讲机试频、手电换电池、图纸折好塞袋、护具扣紧、备品分装。读者看到实物到位，才会相信“真的准备妥了”。
6. **收在行动前一刻**：不贪心把真正的硬冲突硬塞进同一章；把“刚踏进门槛 / 信号响起 / 动手前最后一秒”留作章末钩子，把爆发交给下一章。

## 二、行动章 / 探索章

写小队探查、潜入、搜证、开荒或护送时，核心禁忌是“走两步停下来开讨论会”。

### 执行要点

1. **讨论分散在移动与干活中**：猜测、经验判断、风险提醒全部插在“边走、边看、边清理路障、边测设备”的动作间隙里，让空间一直在往前推进。
2. **角色各说自己那一层**：
   - **带队人**：压路线框架、规矩、推进节奏与回撤红线；
   - **各专业位**：只说自己手里那一块（设备/野路经验、机关/规则/样本判断、侦查/防卫边界）；
   - **沉默角色**：继续保持少话，只在关键节点补一个动作或一句短信号，不为了“信息齐全”强行分台词。
3. **带队先压框架，专家再补边界**：保持信息完整而不重复，前一个人说过的大方向，后一个人直接顺着往下接细则。
4. **普通赶路从简，越往里越不对才展开**：顺利无事的路程压缩成两三句；把笔墨留给异常逐步升级的地方：
   - 入口被封或留下人为撬痕；
   - 地形收窄、塌方或结构松动；
   - 仪器/感知受干扰或读数漂移；
   - 残留的旧交手痕迹或异常物件；
   - 空间压迫感与光线/温度变化。

## 三、分赃 / 盘点 / 换装场景

打完硬仗、探完险或做成大单后的结算章，是读者最有成长体感的高爽段落。不要写成干巴巴的流水账清单，核心目标是**让读者直观看到“主角的战力结构 / 资源结构变了”**。

### 1. 现场分赃（团队结算）

- **先立规矩，再按贡献与性格落地**：提前说过的分成比例先摆在明面，再结合现场出力、谁能用上做微调。
- **防止“熟人局默认占便宜”**：如果主角出于低调或客气主动报了偏亏的方案，队里应有讲究规矩的人出面把公平补回来——这既立住队友的信誉，也让读者心里舒坦。

### 2. 回家盘点与换装（三层顺序）

把收获按“兑现急迫度”分成三层依次处理，节奏最顺：

1. **第一层：马上能用上的主力件**：直接替换旧装备、补齐短板、立刻提升当下战力或手段的硬货。
2. **第二层：需要加工、适配或交换的资产**：暂时用不上，但修一修、炼一炼、拆解研究或拿去换钱换资源就能发挥大用的东西。
3. **第三层：暂时看不懂用途的留底件**：看不透底细、风险未明或缺少前置条件的物件，单独封存收好（顺手埋下后续线索或伏笔）。

### 3. 写出“鸟枪换炮”的升级感

写到主角的新主力武器、护具、核心工具、消耗品或功法/技能时，顺手带清四点（揉进试用动作和短判断里，不列表背书）：
- **品阶 / 档次**（比原来高了多少）；
- **品相 / 状态**（全新、有暗伤、还是需要保养）；
- **当前用途**（具体解决原来哪个痛点）；
- **下一步打算**（旧件怎么处置、新件打算配什么练/用）。

## 四、交易 / 采购场景

买卖、寄拍、典当、黑市换货要写得像真的在做生意，有信息博弈，而不是“报个价 → 掏钱拿走”。

### 商家介绍高价货的四要素

卖方推销关键货品时，不能只空喊“很适合你”，也不能只报个价格，至少落地这四项：

1. **品阶 / 规格**：货在行里算哪一档，成色如何。
2. **核心功能或上限**：最硬的本事是什么，能扛住多大强度或解决哪类问题。
3. **使用门槛 / 限制**：需要什么前置条件、消耗什么代价、什么情况下容易失效。
4. **适用场景或人群**：什么路数的人、在哪种局势下用它最值。

### 大额采购与议价节奏

若主角不是单买一件小东西，而是整单采购多件货品，大额让利优先按真实商业习惯走三步：

> **整单算价 → 给折扣（或搭赠实用小件） → 抹零成交**

示例流程：掌柜拨算盘报出三件货单价与总价（如合计一万四千六百） → 按熟客或整单规矩打九折（一万三千一百四十） → 主角顺手把门槛最脆的那项售后或配件要进单子里，掌柜干脆抹零按一万三千成交。这样既真实，又能顺带展示人物的精明与人情分寸。

## 五、文内规则册子场景

当一章的核心戏份是主角拿到一本行业规程、典籍残卷、货册清单、密档或门规手册时，把它写成一个**有互动的小场景**，而不是把设定原文粘贴进正文：

1. **先给载体质感**：纸张新旧、批注笔迹、装订方式、有没有被人撕页或划线（载体本身就是信息）。
2. **走四步释放法**：
   - 点出册名；
   - 短摘一句最关键的条款或引言；
   - 主角拿自己已经熟悉的旧知识/旧经验往回套，瞬间打通理解；
   - 合册或记下关键一条，马上回到眼前的人际互动或行动决策。
3. **留白不讲全**：这一场只让主角“看懂跟眼下有关的这一两条”；整本册子其余内容，留到后文真正遇到对应麻烦时再翻出来对照，既不闷，还能做长线呼应。
