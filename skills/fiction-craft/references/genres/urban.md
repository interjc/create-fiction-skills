# 都市题材包（职场 / 逆袭 / 异能都市）

> 题材 ID：`urban`。核心叙事契约：在读者熟悉的现代生活规则、金钱秩序与社会关系中，用信息差、专业手腕或隐秘超常能力撬动现实困境，制造极强代入感的反差与代偿。

## 读者期待

- **真实痛点上的精准代偿**：读者每天都面对通勤、账单、甲方刁难、职场甩锅和人情冷暖；主角解决的问题越贴近真实生活（如保住饭碗、拿回被抢的署名权、凑齐手术费），破局时的爽感越直接。
- **规则缝隙里的专业压制**：相比单纯靠拳头或天降神豪，“翻出合同补充条款当场反将一军”“在所有人束手无策的产线故障里三分钟定位病灶”更让人信服。
- **日常表皮下的隐秘反差**：如果带有异能或隐藏身份，最迷人的是“白天在写字楼改报表、修仪器，夜里在另一套秩序里定生死”的双重张力。
- **阶层与尊严的可见变化**：租屋换大窗、账单清零、曾经敷衍自己的前台或客户态度一百八十度转弯，这类具体生活质感的跃迁比空喊身价数字更抓人。
- **最反感的违约**：现代社会常识崩坏（保安随便查银行流水、当街杀人毫无监控后果）、以及主角赢了钱却变得像自己讨厌的霸道恶霸。

## 核心爽点

- **专业拆招反杀**：对手拿行业黑话、流程卡脖子或技术壁垒压人，主角用更扎实的实战细节当场破局。例：副总监拿海外标准质疑设计图不合规，主角直接点开对方引用条款的修订附页，当众念出去年作废的日期。
- **马甲 / 底牌局部曝光**：长期低调的小人物在不经意间露出一角真实人脉或超常能力，令轻视者集体失语。例：被物业拦在货运电梯外的维修兼职生，顺手接起电话报出园区总控室的内部短号，三秒后保安队长亲自跑来刷卡。
- **危机节点一锤定音**：在所有人准备背锅散伙的倒计时里，主角独自扛下关键节点并交付超预期结果。例：上线前两小时支付接口雪崩，他绕过主控台直接改写缓存分片策略，监控大屏的红灯在五分钟内一排排转绿。
- **资源 / 渠道反封锁**：反派联合同行断供、撤资或封杀，主角却早已握有替代方案或上游话语权。例：供货商临时撕毁协议坐地起价，主角笑着把对方的备用原料批号推过去——那批货的唯一检测实验室昨天刚签了他的独家委托。
- **前倨后恭的现实落差**：用冷静克制的日常反应，映照对手得知真相后的慌乱失态。例：曾经把简历直接丢进碎纸机的主管端着两杯手冲咖啡站在工位旁，主角只抬头说了一句“报告发你邮箱了，先看第三页”。

| 爽点类型 | 适用章节权重 | 最小铺垫建议 | 写法关键 |
|---|---|---|---|
| 专业拆招 | `normal` / `heavy` | 1–3 章（先立清楚对方卡脖子的具体条款） | 只需一个可验证的硬细节，不要长篇科普 |
| 马甲露角 | `heavy` | 3–8 章（多次承受不对等的轻视） | 只露一角立刻收手，留给旁人自己脑补 |
| 危机兜底 | `heavy` | 2–4 章（倒计时压力与众人退缩） | 用客观仪表、时间、签字动作体现逆转 |
| 渠道反锁 | `heavy` | 4–6 章（提前埋下替代方或检测方接触） | 对手刚把话说死时再掏出后手 |
| 前倨后恭 | `light` / `normal` | 承接上一场公开逆转 | 主角越平静体面，反差越有力量 |

## 常见结构与节奏

### 开篇切入（黄金三章）

- **困境压顶型**：背锅被裁、房租到期、亲人急需用钱，同时获得异能、系统或翻盘线索，三天内必须先止血。
- **隐忍亮剑型**：在公司或家族里长期干脏活累活却被夺功，第一天起决定不再替别人兜底，当场交出烂摊子。
- **日常异变型**：普通都市职业（外卖员、夜班电工、实习审计、急诊护士）在加班夜意外接入异常规则或地下订单。

### 卷级弧线（项目 / 危机升级链）

每一卷围绕一个可结算的现实目标展开，形成“问题→站队→破局→升格”五步：

1. **接手烫手山芋 / 遭遇挤压**：进入新项目、新岗位或被卷入突发事件，明确亏损红线与期限。
2. **摸清利益链与真实话语权**：辨认谁表面主事、谁暗中抽成、谁手握最终签字权。
3. **试错与暗中积攒筹码**：一边用常规手段应付明面考核，一边利用特长或异能建立别人看不见的底牌。
4. **关键现场正面摊牌**：竞标会、验收会、股东会或对质现场，一轮把账算清。
5. **回报兑现与圈层跃迁**：拿到现金、股份或话语权，同时进入更大一级的规则场（行业巨头 / 监管层 / 里世界组织）。

### 单章与日更节奏

- 都市对话密度高，日常消费、饭局闲聊必须承担“漏出线索、立住关系或反衬压力”的功能，不在单章内做无冲突的纯购物、买车流水账。
- 日更两章常用组合：**第 1 章**抛出甲方新刁难或规则陷阱（`B` 级钩子）→ **第 2 章**查出破绽并在饭局/会场反制（`A` 或 `S` 级钩子：新人物或更大监管方介入）。

## 体系设计要点

- **现实常识兜底（信用基石）**：公司股权、劳动仲裁、招投标、医院流程、警方权限哪怕做戏剧化简化，也不能出现硬伤（如普通保安随意调银行流水、口头一句话冻结上市公司账户）。
- **异能 / 金手指的“社会暴露代价”**：若是都市异能或系统文，必须写死“不能当众肆意施展的原因”（街头监控密布、异能反噬、特殊部门盯防、使用需等价消耗），否则主角会迅速失去生活张力。
- **金钱与人脉的真实刻度**：1 万块解决什么问题、100 万撬动什么资源、1 亿面临什么审计和对手，全书必须共用同一把尺子；初期为房租发愁，中期不该随手撕毁千万合同。
- **现代信息痕留存**：手机录音、监控录像、转账回执、聊天记录既是主角反杀的铁证，也是限制主角乱来的枷锁——设计冲突前先核对周围有没有摄像头与手机。

### 体系自检三问

1. 这场冲突如果发生在大白天或公共场所，路人手机和园区监控拍到了怎么办？谁来善后？ `[模型]`
2. 对手能动用的打压手段，是否符合他在公司或社会里的真实职权，而不是“一句话封杀全行业”？ `[模型]`
3. 如果去掉金手指或隐藏背景，主角自己的专业动作是否依然站得住脚？若需调高或收紧能力暴露风险，须由作者拍板写入 `canon.md` `[作者]`

## 人物配置

- **主角定位**：核心魅力在于“情绪稳定 + 执行力强 + 懂人情世故”。忌写成毫无生活常识的莽夫，或只靠吼叫威胁压人的暴发户。

| 角色位 | 常见套路 | 去脸谱写法 | 与主角的核心锚点 |
|---|---|---|---|
| 甲方 / 伯乐 | 无条件砸钱倒贴主角 | 有自身 KPI 和算盘，赏识主角是因为他真能替自己扛事、赚钱 | 业绩绑定、风险共担与信任递增 |
| 体面型对手 | 逢人就骂穷鬼的蠢反派 | 笑脸迎人、流程全合规、擅长借规章和舆论把人按死在规则里 | 晋升名额、核心客户或项目归属 |
| 基层烟火同盟 | 只会喊主角大佬的跟班 | 修车老板、律所实习生、老科室护士，各有一摊生活烦恼但讲义气 | 信息互通、地面视角与生活照应 |
| 家族 / 旧关系阻力 | 聚会必定集体嘲讽求打脸 | 怀着过时认知和现实焦虑，看人下菜碟但也会在利益面前快速变通 | 旧情牵绊与现实处境的拉扯 |

## 常见雷区

- **霸总式无逻辑撒币**：反派莫名当众羞辱主角，主角打个电话十辆豪车堵门、买下整栋楼开除保安。**改法**：把冲突根源落在具体利益（竞标名额、专利归属、核心渠道）上，用规则和筹码反杀。
- **行业外行硬装专家**：满篇“五分钟攻破银行系统”“一眼看穿十年假账”却说不出一个具体破绽。**改法**：不懂的专业深水区用“一个精确小动作 + 客观结果”带过，绝不展开假专业长篇大论。
- **全员拜高踩低模板**：亲戚、前任、同学聚会永远只有“嘲讽→亮瞎眼→跪地求饶”一个模子。**改法**：让尴尬停留在对方僵住的微笑、突然改口的称呼和沉默的酒杯里，留出生活真实感。
- **现实地名与机构未脱敏**：直接写进真实医院、高校、品牌全称或真实人物，触发平台审核或法务风险。**改法**：全部改写为架空代称，并把易混原型词填进 `.fiction/config.json` 脱敏词表。
- **异能彻底脱离都市秩序**：动辄当街毁楼却毫无舆论与官方后续。**改法**：写清事后遮蔽机制、目击者记忆/舆论处理或官方接口人收尾。
- **感情线或配角完全悬浮**：除了给主角鼓掌或找茬之外没有任何自己的生活切片。**改法**：给重要配角留一两个带烟火气的日常细节（赶末班车、给孩子报辅导班、怕扣绩效）。

### 审校快速复核

- 委托 `fiction-review`（或 `fiction-chapter`）运行 `lint.mjs`（未安装时人工核对），确认已登记的脱敏词表与公历年份正则无阻塞命中。 `[脚本]`
- 通读排查词表之外的漏网现实地名、机构全称或品牌映射（脚本只拦截已登记条目，不保证脱敏已完备）。 `[模型]`
- 核对本章资金数额与人物消费水平是否仍对齐本书刻度。 `[模型]`
- 发现新出现的现实原型词或需要调整资金/能力尺度时，由作者确认后补充进 `.fiction/config.json` 或 `bible/world-rules.md`。 `[作者]`

## 钩子素材

- **截止前突发变故（`S` 级）**：距离标书递交只剩十分钟，加密 U 盘插上电脑却弹出文件损坏提示，而备用邮箱已被人锁死。
- **推门而入的意外人物（`S` 级）**：酒局上对手正得意宣布收购完成，包厢门推开，坐在首位买方席的人摘下眼镜看向主角。
- **双线资金/消息撞车（`A` 级）**：手机同时收到两条短信——一条是母亲手术费到账通知，另一条是匿名发来的“你刚才动用的账户已被风控标记”。
- **双面身份濒临撞车（`A` 级）**：白天在会议室对面坐着的严厉合规总监，晚上一模一样缺了一颗铆钉的皮包出现在地下交易摊位对面。
- **内部通报前夜（`A` 级）**：所有人都以为风波已经压下，主角邮箱却躺着一份抄送全公司的审计问询函草稿。
- **追回尾款后的克制抉择（`B` 级）**：拿到拖欠半年的尾款后，他没有立刻退掉老旧合租屋，而是先把修水管的钱转给房东，决定搬走前先把那张旧单据查清楚。

## 短剧改编要点

### 保留与放大

- 都市短剧可借现代日常空间（办公室隔间、餐厅包厢、医院走廊、小区门口）快速落地拍摄，不必依赖复杂特效；建议把主要冲突收拢到 2–3 个可复用的室内外主景。
- 放大签字落笔、转账提示音、工牌摘下/戴上、手机亮屏消息等近景符号。

### 必须删改

- 大段财务报表口头分析、冗长的通勤与租房看房心理独白、超过三层的公司股权架构说明。

### 前 3 秒抓手与卡点落位

- **动作外化示范**：小说“他心里快速盘算完这批货的利润率，决定趁对方没反应过来先签补充协议” → 短剧可落成：

```markdown
## 场景1：会议室·内·日
人物：项目组长、采购代表
△ 他用计算器敲出四个数字，屏幕朝外推过去，把笔直接拍在补充协议上。
【特写】协议末端违约金一栏红圈刺眼。
项目组长：九折，现在签；十一点一过，按原价翻倍。
```

- **前 3 秒**：强现实痛点动作（辞职信拍在脸上 / 急诊室外被拒签字 / 婚礼现场收到解约通知）。
- **付费卡点**：落在“主角把关键底牌文件翻面拍在桌上刚要念名字”或“隐藏大人物推开大门走进宴会厅”的定格瞬间。

## 与套件的接口

### 核心 bible 文件

- `bible/characters.md` 与 `bible/character-dynamics.md`：都市高度依赖职场站队与人脉动态；只在饭局、谈判或项目结算**真正改变了人物关系、站队或信任现状**时，在 `character-dynamics.md` 追加一行，无实质变化的一般过场不记流水账（[SB §4](../formats/project.md)）。
- `bible/timeline.md`：合同期限、项目倒计时、排班休假与异能冷却写清绝对日期，正文只写相对时间口径（[SB §4](../formats/project.md)）。
- `bible/inventory.md`：追踪关键资金池、证件、股权协议或异能消耗媒介的持有与转手；规则与尺度说明回到 `world-rules.md`，已拍板设定看 `canon.md`（[SB §3–§4](../formats/project.md)）。
