# 言情题材包（古言 / 现言）

> 题材 ID：`romance`。核心叙事契约：在鲜明的外部障碍或内心防线制约下，写出两个人从试探、拉扯到彼此确认与共同承担的情感共振，同时用具体细节兑现情绪价值。
>

## 读者期待

- **双向拉扯的情感张力**：比起一见钟情立刻发糖，读者更吃“想靠近又因立场/顾忌而克制”“一句话听出言外之意”的微妙电流。
- **旗鼓相当或互补的羁绊**：双方都要有独立的站位、判断力和底线，不是单方面拯救或无脑依附；彼此的偏爱必须建立在“看见并尊重对方的难处”上。
- **细节里的心动与偏爱兑现**：高甜不在空洞的“我爱你”台词，而在记住对方忌口、雨夜倾斜的伞、当众不动声色把话接过去护住体面。
- **情感线与主线互为燃料**：无论是古言宅斗权谋还是现言职场生活，感情升温必须推进现实局势，现实危机也必须反过来逼出情感抉择。
- **最反感的违约**：全员降智靠误会水几十章、男女主没有感情过渡突然深情、或口号喊大女主实际永远靠男主兜底。

## 核心爽点

- **当众护短与隐秘偏爱**：旁人冷眼或故意刁难时，平时克制寡言的一方不讲虚礼，直接用行动把人划进自己阵营。例：席间族老借着敬酒敲打她出身低微，对面一直慢条斯理剥橘子的世子却将整盏茶推到她手边：“她手冷，这杯我代她喝。”
- **试探破防与克制失守**：看似滴水不漏、永远体面的人，因对方一句无心话或一个动作忽然露出一瞬失态。例：合租半年他永远准时十点回房，那天她发烧迷糊抓着他袖口问了一句“你会走吗”，他站了整夜没抽回那截袖子。
- **旧身份认出与重逢对峙**：久别重逢或暗中往来的知己当面撞破身份，旧怨与新情同时翻涌。例：甲方代表念完苛刻的修改意见，抬头却看见对席的新主创左手虎口那道当年为救自己留下的烫伤疤。
- **联手破局的默契升温**：危机中无需长篇商量，一个眼神交汇便各自补位，事后短暂喘息时感情水到渠成。例：公堂上对方递来的账册少了一页，她立刻接话报出三年前旧仓存数，两人当堂把贪墨案钉死。
- **误会当场拆穿不内耗**：挑拨离间刚开口，主角直接对质或凭信任反将一军，给读者极度舒适的“长嘴了”爽感。例：同事刚在走廊故意提起昨晚看见他送女生回小区，她反手点开共享行程：“那是我表妹，他昨天顺路送完人还给我带了夜宵。”

| 爽点类型 | 适用章节权重 | 最小铺垫建议 | 写法关键 |
|---|---|---|---|
| 当众护短 | `heavy` / `normal` | 1–3 章（先立住旁人的轻视或刁难） | 护短动作干脆，不讲长篇大道理 |
| 克制失守 | `normal` | 3–6 章（先反复建立他平时的冷淡规矩） | 失态只留半拍，越克制越撩人 |
| 掉马认出 | `heavy` | 5 章以上（前期积累双重视角信息差） | 认出瞬间停在眼神与静默里，别急着解释 |
| 联手破局 | `heavy` | 2–4 章（各自握有半块拼图或不同专长） | 双方都出真力，不许一方单向躺赢 |
| 拆穿挑拨 | `light` / `normal` | 当章或前 1 章埋挑拨动机 | 直接拿实锤回击，把尴尬留给挑事者 |

## 常见结构与节奏

### 开篇切入（黄金三章）

- **契约绑定 / 同居合作型**：先婚后爱、协议婚约、合租或项目捆绑，用日常边界试探与互惠条款直接起手。
- **错位重逢 / 旧恨翻涌型**：昔日恋人、退婚对象或旧日同窗在全新身份下狭路相逢，前史张力一秒拉满。
- **危局搭伙型**：古言换亲或家门突遭变故、现言行业危机被孤立，两人因共同利益被迫先联手稳住局面。

### 卷级弧线（情感五阶梯）

切忌十章之内爱得死去活来、后面七十章全靠第三者强行拆散。推荐按卷推进五阶关系弧：

1. **戒备与错位认知**：双方带着各自偏见或利害目的交锋，建立“这人不简单 / 这人真难搞”的第一印象。
2. **合作中的局部改观**：在共同应付一场外部麻烦时，看见对方私下里真实却不张扬的一面。
3. **试探与防线松动**：出现第一次不可逆的越界关心或护短，双方各自慌乱但嘴硬不认。
4. **危机下的选择确认**：面临利益冲突或误解考验时，一方在关键时刻坚定站在另一方身前，关系正式定调。
5. **并肩对抗更大阻力**：从“彼此试探”转向“共同面对门第、家族、行业竞争或朝堂风波”。

### 单章与日更节奏

- 感情线与事业/宅斗/职场线交叉推进：不连写超过三章毫无现实推进的纯发糖日常，也不连写超过五章核心配对完全不见面、无互动的纯外围剧情。
- 日更两章常用组合：**第 1 章**共同处理麻烦或遭遇外人发难（`B` 级钩子：关系出现微妙裂隙或试探）→ **第 2 章**护短反击与私下余波（`A` 或 `S` 级钩子：心动细节或旧秘密露头）。

## 体系设计要点

- **障碍必须有真实重量**：两人的阻力不能只靠“男主傲娇不说”“女主自卑躲避”硬撑，而要来自**结构性矛盾**（古言：门第礼法、两家旧怨、立储站队；现言：竞业避嫌、上下级伦理、异地发展、家庭债负）。
- **心动触发器（可验证的小事件）**：每次关系向下一阶移动，都必须挂靠一件具体小事（如替对方瞒下一桩风险、宁可自己吃亏也保住对方的体面），绝不能毫无来由地“突然深爱”。
- **古言与现言各自的约束边界**：
  - **古言**：尊重时代礼法、男女大防、宗族声誉与婚姻制度；越是外人面前讲究规矩，私下越矩半寸的眼神或指尖擦碰才越有张力。
  - **现言**：尊重现代职场规则、成年人时间成本与法律边界；真爱不等于替对方违规开绿灯或无视工作底线。
- **情绪余韵留白**：关键心动瞬间写完动作和停顿即可收手，把呼吸与心跳留给读者脑补，不要紧接着写一段“这一刻她心头涌起一股莫名的悸动”。

### 体系自检三问

1. 阻碍两人在一起的难题，是只要“开口说清”就会消失的假误会，还是实打实的立场与利益冲突？ `[模型]`
2. 本章男主或女主做出的让步或护短，是否符合他一贯的性格底线与现实代价？ `[模型]`
3. 这一段亲密戏或吵架戏结束后，两人的关系刻度是否比三章前实质挪动了一步？若需调整双方主线核心障碍或感情线里程碑，须由作者拍板写入 `canon.md` / `plot-outline.md` `[作者]`

## 人物配置

- **女主（独立且自洽的行动核）**：哪怕开篇处境弱势，也必须有自己的手艺、谋生本事或看透局势的脑子；接受对方帮手是因为当下策略划算或互利交换，而不是坐等拯救。

| 角色位 | 常见套路 | 去脸谱写法 | 与主角的核心锚点 |
|---|---|---|---|
| 男主（核心对象） | 只会冷脸、壁咚、强取豪夺 | 有克制力与真实缺陷，对别人讲规矩、唯独对你留半寸余地，关头肯放低身段 | 利益互补、旧日牵绊与底线共鸣 |
| 对照系闺蜜 / 同僚 | 只负责夸男主好或催婚 | 有自己的职业或生活烦恼，能一针见血点破主角嘴硬的心思 | 情绪树洞与现实参照系 |
| 家族 / 长辈阻力 | 为拆散而拆散的恶婆婆/老顽固 | 站在家族存续、门第安全或自身安稳的角度算账，只要看到足够筹码或真心也会松口 | 宗族体面、利益交换与亲情拉扯 |
| 同赛道竞争者 | 无脑端酒泼自己栽赃 | 在正当赛道（才名、晋升、联姻筹码）体面争抢，甚至有让人敬佩的体面一面 | 有限资源归属或不同理念冲突 |

## 常见雷区

- **工业糖精与硬撩**：认识第一天就无限贴脸壁咚、摔倒必精准接住对视十秒、每句台词都在刻意耍帅。**改法**：把亲密藏在具体事务里（修伞、递药、借光对账），先立信任再有肢体靠近。
- **反复降智制造假误会**：明明一句就能问清楚的事，两人硬要各自脑补冷战三十章。**改法**：把矛盾从“不长嘴”升级成“就算说开了也摆在眼前的立场或家族冲突”。
- **伪大女主真娇妻**：口号喊着搞事业，遇到难关永远靠男主一道密旨/一个电话摆平。**改法**：核心危机必须由女主自己用专长或布局破局，男主最多负责挡掉不讲理的场外黑手。
- **第三者低级陷害循环**：女配只会自残栽赃或下药，循环三卷毫无新意。**改法**：减少低智雌竞，把矛盾放进真实事业、家业或政局博弈里。
- **关系跃迁断档**：上一章还剑拔弩张，下一章突然互诉衷肠。**改法**：写完互动章顺手更新 `bible/character-dynamics.md`，检查阶段变化是否顺滑。
- **配角工具化献祭**：为了衬托男主深情，所有追求女主的人全员丑陋油腻或心术不正。**改法**：让配角拥有体面的闪光点，主角选定彼此是因为“恰好同频”，而不是“其余人都像坏人”。

### 审校快速复核

- 委托 `fiction-review` 运行 `lint.mjs`（未安装时人工通读），检查古早套话与禁用词命中情况（参数见 `lint.mjs --help`）。 `[脚本]`
- 委托 `fiction-chapter` / `fiction-continuity` 生成 `brief.mjs` 简报，核对核心且非常驻人物的缺席提醒。 `[脚本]`
- 对照 `appearances.md` 人工复核双主角均设`常驻`时的实际出场间隔，并删改直白说教台词，保留动作或半句停顿。 `[模型]`
- 决定两人的核心障碍拆解时机与关键节点感情走向时，交作者拍板后同步更新 `character-dynamics.md` 或 `plot-outline.md`。 `[作者]`

## 钩子素材

- **试探击中软肋（`A` 级）**：原本客客气气谈正事，她随口问起那枚旧书签的来历，对面一直稳稳端着茶盏的手忽然一顿，茶水漫过杯沿。
- **被迫同处一室（`A` 级）**：暴雨封路或客栈锁门，两个刚在白天划清界限的人，隔着一扇屏风各自听见对方的呼吸与翻页声。
- **马甲 / 秘密临近曝光（`S` 级）**：她连夜赶完匿名的反驳稿刚发出去，一抬头却看见对方手机屏幕上弹出的作者后台提醒。
- **当众护短的临界瞬间（`S` 级）**：正要被迫签下退让协议时，大厅门被人从外面推开，门口那道身影只扫了一眼桌上的笔：“谁准她签的？”
- **以为离开却仍在场（`A` 级）**：她拖着箱子走出雨夜车站，回头把伞放回门房，却在街角路灯下看见那辆还没熄火的黑色轿车。
- **未寄出的信物与余温（`A` 级）**：收拾搬家纸箱时，她从旧书夹层里抖出一张自己当年留下的电影票根，背面多了一行陌生的钢笔字。
- **克制让步的决定（`B` 级）**：她没有拆穿他替自己垫付违约金的拙劣借口，只是把那杯还温着的姜茶握回手心，决定留下来把收尾项目做完。

## 短剧改编要点

### 保留与放大

- 建议多用竖屏中近景与特写放大微表情与手部动作，如眼神停留、一秒变脸、反差护短、替人挡酒或撕毁不公协议的瞬间，减少静态长对白。

### 必须删改

- 超过三句话的心理纠结独白、与感情推进无关的冗长职场/宅斗礼仪铺垫、缓慢平铺的暧昧日常（压缩为 2–3 场高浓度交锋）。

### 前 3 秒抓手与卡点落位

- **动作外化示范**：小说“她心里突然觉得很委屈，却又不想在这么多人面前示弱” → 短剧可落成：

```markdown
## 场景1：宴会厅偏廊·内·夜
人物：女主角、对接人
△ 她指尖把合同边角捏皱了一瞬，随即松开抚平，抬头冲对面笑了一下。
【特写】她无名指被纸边划出一道红痕，很快又被袖口遮住。
女主角：（平静）行，条件我认，现在签。
```

- **前 3 秒**：强关系冲突直接贴脸（退婚现场转身牵住反派叔父的手 / 分手夜发现新顶头上司是前任）。
- **付费卡点**：停在“男主一把扣住手腕压低声音开口”或“当众撕掉伪证亮明撑腰身份”的瞬间。
- **多线并轨提醒**：写言情最忌“事业线写顺了就把感情线晾十章”，每次阶段任务结束务必留半章给两人独处结算。

## 与套件的接口

### 核心 bible 文件

- `bible/character-dynamics.md`：言情的绝对核心。**只在双人关系、态度或自身弧线实际发生变化时**记录一行`变化`与`现状`（两人当前对彼此的真实印象看最新一行`现状`），关系无波动的一般日常不必硬记流水账（[SB §4](../formats/project.md)）。
- `bible/characters.md`：登记双方各自不愿示人的过往或秘密（`作者真相`）、**读者此刻对角色的认知**（`读者已知`，注意不要写成男女主彼此眼中的主观印象），以及习惯动作/说话风格。
- `bible/subplots.md`：用 B 级或 C 级支线专门追踪重大心结、信物往来与副 CP 进展。
- 关于 `appearance.gap_warn`：`brief.mjs` 的缺席提醒只作用于**级别为`核心`、非`常驻`且不在`休眠卷`内**的人物（见 `fiction-chapter` 或 `fiction-continuity` 附带的 `brief.mjs --help`）。若想利用 `gap_warn: 5` 防止双主角之一掉线太久，须把至少一方设为`常驻：否`；若双主角均设为`常驻：是`，则不会触发该提醒，需改由人工复核 `appearances.md`。
