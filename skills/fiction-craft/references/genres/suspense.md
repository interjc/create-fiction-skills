# 悬疑 / 推理题材包

> 题材 ID：`suspense`。核心叙事契约：与读者展开一场公平而精密的智力博弈——所有异常必有迹可循，所有反转必须早有伏笔，用严密的因果链和情绪压迫感把读者拽到最后一页。
>

## 读者期待

- **公平解谜与回看爽感**：真相揭晓时，读者往回翻十几章，发现那个装反了的门把手、慢了两分钟的挂钟、随口叫错的小名早已明晃晃摆在正文里，而不是临终场强行编新设定。
- **正常秩序渗出违和的压迫感**：恐惧和紧张不必靠血腥渲染，而是日常细节里的一点不对劲——门锁多了一道划痕、合影里多出一双脚、本该空着的病床被铺得整整齐齐。
- **剥茧抽丝的推演快感**：看着主角把嫌疑人精心编织的不在场证明、情绪表演和伪证一层层剥开，直到只剩唯一站得住脚的解释。
- **有重量的人性动机**：作案手法再精巧，如果凶手没有非这样做不可的切身利害，故事就会变成冰冷的机关拼图；动机反转往往比手法反转更有后劲。
- **最反感的违约**：关键线索从未在正文出现（机械降神）、或全书一半就开始用旁白提前剧透“他不知道凶手就在门外”。

## 核心爽点

- **物证打脸推翻伪证**：嫌疑人面对质询对答如流，主角不急着争辩，只拿出一个微小却无法抵赖的物理矛盾。例：嫌疑人坚称自己整晚待在暖气充足的书房，主角却把窗台那盒早已融化又重新冻歪的黄油推到他面前。
- **时间线对表破产**：看似天衣无缝的不在场证明，在把多方证词、车程、潮汐或日常节律并排对齐后瞬间崩塌。例：三名证人都说七点十分听见门响，可楼下报时钟那天因为停电慢了整整一刻钟。
- **假性结案后的陡然翻盘**：读者刚以为找到真凶松了口气，一条被忽略的副线细节忽然把整套推理倒扣过来。例：替罪羊在审讯室签完字的那一刻，法医却从死者指甲缝里检出了不属于任何嫌疑人的老式漆灰。
- **请君入瓮反设陷阱**：主角不再被动追线索，而是故意释放一个只有真凶才能看懂的错误信号，逼对方自己露马脚。例：办案组故意在内部简报里把失踪账本写成蓝皮，当夜只有真正进过档案室的人才托人去问“那本灰布面的是不是也烧了”。
- **视角补全重构记忆**：补上缺失的十秒钟或换一个在场者的站位，原本温馨或普通的画面瞬间变冷。例：全家人一直以为外婆临终前是指着墙上的老照片笑，直到修表匠指出照片背面露着半截拆迁通知。

| 爽点类型 | 适用章节权重 | 最小铺垫建议 | 写法关键 |
|---|---|---|---|
| 物证拆穿 | `normal` / `heavy` | 2–5 章（前期正文必须写过该物或环境条件） | 证物越日常，拆穿时越惊艳 |
| 时间对表 | `heavy` | 3–6 章（提前埋好各个独立时间点） | 尽量不靠长独白，用对比表格或现场重演 |
| 假案翻盘 | `heavy` | 半卷以上（给足第一层合理解释） | 翻盘后必须同时兼容前面所有旧线索 |
| 设局引蛇 | `normal` | 1–3 章（先定好信息差与知情范围） | 陷阱成败要看得见风险，不能稳赢 |
| 视角重构 | `heavy` | 跨卷或单案结尾 | 改变解释权，不篡改前文已发生的客观事实 |

## 常见结构与节奏

### 开篇切入（黄金三章）

- **异常现场型**：前 300 字直接抛出违背常理的物件、尸体或失踪状态，立刻建立具体疑问（谁动了它 / 为什么这样摆）。
- **微小违和渗入型**：主角在日常工作中遇到一件看似无害的小错位，第二章发现它牵连着多年前的旧案或失踪者。
- **倒计时危机型**：主角收到匿名预告或被直接列为头号嫌疑人，必须在限定小时数内自证或救出下一位目标。

### 卷级弧线（双线三层信息架构）

长篇悬疑建议严格维护**表面事件线 + 深层真相线**，并拆成三层信息分别记账：

| 信息层 | 记在哪里 | 谁能看见 | 卷级推进节奏 |
|---|---|---|---|
| 第一层：表面事实 | `outline.md` / 正文 | 读者 + 在场人物 | 开局抛出异常现场与基础物证 |
| 第二层：误导假设（红鲱鱼） | `foreshadows.md`「读者已知」 | 读者 + 主角（暂信） | 中段顺着部分证据锁定“合理替罪羊” |
| 第三层：底层真相 | `foreshadows.md`「作者真相」 | 仅作者（严禁正文泄底） | 尾声由一块被忽视的硬细节推翻二层、直指三层 |

### 单章与日更节奏

- 悬疑最忌连续两章原地开会复盘。每章必须推进至少一项：**拿到新物证、推翻一个既有假设、看穿某人的一句谎话、或危险向主角实质逼近**。
- 日更两章常用组合：**第 1 章**实地勘查或调取记录，出现预期之外的偏差（`B` 级钩子）→ **第 2 章**当场对质或揭开半层真相，立刻接上更冷的疑点（`A` 或 `S` 级钩子）。

## 体系设计要点

- **时空与物理刚性约束**：行车时间、通话记录、门锁朝向、尸温尸斑、天气降水、视线遮挡必须逐条对齐 `bible/timeline.md`。推理读者会拿尺子量时间账，一处硬算错就会毁掉全卷信用。
- **红鲱鱼（正当误导）守则**：误导线索不能靠作者撒谎硬骗读者，而必须“线索本身为真，只是当时读者缺了一块背景拼图”（例如钥匙确实在甲口袋，因为乙趁他睡着时塞进去的）。
- **严格隔离“作者真相”与正文叙述**：真相揭晓前，连主角的心理活动里也不准替作者点破因果；正文只写人物看见的动作、听见的声音和当下能做出的有限判断。
- **信息边界防串台**：每个配角只知道自己亲历或被别人告知的信息。写审讯或对话前先查一遍 `bible/appearances.md`，避免从未到过现场的人突然说出案发细节。

### 体系自检三问

1. 本章用来打脸或破案的那条关键证据，前面正文中是否已经以正常物件的身份出现过？ `[模型]`
2. 把所有嫌疑人的移动时间、车程和通讯点摆进 `timeline.md`，有没有出现物理上赶不及的漏洞？ `[模型]`
3. 把凶手的作案风险和真实收获摆上天平，他非用这种复杂手法不可的理由是否成立？若需调整作案动机或关键时间硬锚，须由作者拍板写入 `canon.md` / `timeline.md` `[作者]`

## 人物配置

- **主角（调查者）**：给主角一把具体可感的专长手艺（如法医痕迹、古董修复、火场勘查、账目审计、老街熟人网），而不是全知全能的“空降神探”；留一处性格盲区或个人旧伤，破案才会有个人代价。

| 角色位 | 常见套路 | 去脸谱写法 | 与主角的核心锚点 |
|---|---|---|---|
| 知情群像（证人） | 全员死鸭子嘴硬或主动坦白 | 每个人都在隐瞒一件与凶案无关的小私事（私情、挪用公款、偷懒），小谎言自然织成迷雾 | 被逼到自身私利边缘时才吐出半句实话 |
| 高段位凶手 / 对手 | 临死前主动长篇交代犯罪艺术 | 懂规矩、有耐心、善用普通人的善意与制度盲区，每步都留好了退路和替罪预案 | 双方共享同一段旧事或同一条逻辑链 |
| 体制内搭档 / 阻碍 | 永远愚蠢并阻挠主角破案的领导 | 按程序、舆情和结案压力行事，需要确凿物证才会批手续，关键时刻也能扛事 | 结案期限与证据标准的拉锯 |
| 日常锚点人物 | 与案情无关的废话邻居 | 用来标定时间流逝、天气变化和主角精神状态落差的普通人（如楼下店主） | 提供无意中记下的时间/物件旁证 |

## 常见雷区

- **机械降神破案**：关键物证此前从未在正文露面，结尾主角突然说“其实我三天前就偷偷送去化验了”。**改法**：哪怕主角暗中留手，也必须在当时写下“他折返从烟灰缸夹走半截烟头”等可见动作。
- **旁白提前泄底**：正文出现“他当时并不知道，这通电话正是凶手设下的局”。**改法**：全部移入 `foreshadows.md` 的`作者真相`栏，正文只留冷峻白描。
- **为反转牺牲动机**：凶手费尽心机布置复杂密室，最后理由竟是“其实他有精神分裂”或“认错了人”。**改法**：先敲定有重量的切身动机，再反推凶手会选什么手法。
- **会议室复读机注水**：两千字全是一群人围着白板重复前十章已经发生过的线索。**改法**：把推理拆进赶路、勘查、翻旧档和当面对质的动态交锋里。
- **法医 / 刑侦常识硬伤**：如随便破门搜查无手续、尸斑与死亡时间乱写、有毒物质气味胡编。**改法**：不确定的专业细节用客观表象描摹，必要时提前核对常识并登记进 `world-rules.md`。
- **主角开局自带全能黑客或万能关系网**：遇到任何查不到的监控、通话或档案，全靠“找认识的哥们一分钟调出来”。**改法**：每一次越界调取信息都要付出时间延迟、人情债或被对方反向察觉的风险。

### 审校快速复核

- 委托 `fiction-continuity`（或 `fiction-chapter`）执行 `foreshadow-scan.mjs`（未安装时人工核对），确认到期、逾期与沉睡伏笔清单，以及 `未来出现方式` 非空等机械约束。 `[脚本]`
- 委托 `fiction-review` 执行 `lint.mjs`，排查泄底禁用词与公历年份命中（参数见 `lint.mjs --help`）。 `[脚本]`
- 逐段阅读排查是否存在脚本未覆盖的作者视角越位剧透（如提前暗示“日后成了铁证”），并复核伏笔`未来出现方式`是否写实可行、时间线是否自洽。 `[模型]`
- 若决定放弃某条支线或改期回收重要伏笔，由作者拍板并在 `foreshadows.md` 写明理由。 `[作者]`

## 钩子素材

- **矛盾新数据出现（`A` 级）**：技术科报告刚发来，死者胃里残留的食物消化时间比所有目击证词早了整整四个小时。
- **监控 / 记录关键缺口（`A` 级）**：整条走廊的画面都完好无损，唯独门前灯灭掉的那两分零八秒变成一片雪花。
- **亡者遗物直指主查者（`S` 级）**：从旧箱底翻出的泛黄借条上，担保人签名栏赫然写着刚推门进来主持案情复盘的上司名字，而门外走廊同时响起反锁门栓的金属声。
- **危险近在咫尺（`S` 级）**：主角刚挂断安慰证人的电话，一抬头却在对方发来的窗外街景照片里，看见了自己楼下的蓝色雨棚。
- **证人当庭反水（`S` 级）**：关键证人推开审讯室门，目光越过办案人落到走廊玻璃外的某个身影上，突然闭紧嘴：“那天晚上我什么也没看见。”
- **时间错位提示（`A` 级）**：退回酒店房间准备休息时，主角瞥见门卫登记簿上自己名字前面那一行，写着一个早就注销的旧车牌。
- **暂缓摊牌的决定（`B` 级）**：对完通话记录的最后一分钟后，他把笔记本合上锁进抽屉，决定今晚先不惊动搭档，等明早物证比对结果出来再当面开口。

## 短剧改编要点

### 保留与放大

- 保留强视觉异常物证（停在特定时刻的表盘、带缺口的票据、反锁的门插销、监控红点）、冷色调对峙与快速交叉剪辑。

### 必须删改

- 超过 20 秒的静态案情复盘对白、复杂的多重社会背景铺垫、没有画面动作支撑的纯逻辑内心独白。

### 前 3 秒抓手与卡点落位

- **动作外化示范**：小说“他把四份笔录里的时间按顺序排开，忽然意识到司机根本来不及走完那段山路” → 短剧可落成：

```markdown
## 场景1：值班室·内·夜
人物：调查员、证人
△ 他把三张车票和一张过路费收据依次拍在桌上，红笔重重圈出两个重合的分钟数。
【特写】两张票据的时间戳同为“19:10”，中间隔着四十公里盘山公路。
调查员：（盯着证人）七点十分，他不可能同时在这两个地方。
```

- **前 3 秒**：直接抛违背常理的惊悚或疑点画面（雨夜门缝渗出红水 / 失踪者的手机在灵堂里突然响起）。
- **付费卡点**：落在“揭开白布看见死者正脸的瞬间”或“主角拿着物证指认凶手‘那这件外套怎么解释’”的停顿上。

## 与套件的接口

### 核心 bible 文件

- `bible/timeline.md`：悬疑的绝对核心。逐条锁死绝对时间、硬锚/软锚、车程与时限，正文严禁与约定口径冲突（[SB §3–§4](../formats/project.md)）。
- `bible/foreshadows.md`：逐条严格分开填写`读者已知`与`作者真相`（[SB §1](../formats/project.md)）；到期、逾期、沉睡与 `未来出现方式` 非空等机械校验可委托 `fiction-continuity` 运行 `foreshadow-scan.mjs`（见 `foreshadow-scan.mjs --help`），而“未来出现方式写得是否写实合理”须靠模型与作者人工判断。
- `bible/characters.md` 与 `bible/appearances.md`：写清每位知情者的信息边界，每章完稿后按实际正文补录出场记录（[SB §4](../formats/project.md)）。

### `.fiction/config.json` 建议片段

```json
{
  "book": { "genres": ["suspense"] },
  "rhythm": { "beat_every": [2, 4], "external_event_max_gap": 2 },
  "foreshadow": { "due_window": 5, "dormant_after": 15 },
  "lint": { "desensitize": { "exact_years": true } }
}
```

### `.fiction/lint-patterns.txt` 建议片段

```text
[custom:block]
殊不知 => 严禁旁白提前泄底，改写为角色可见的客观细节
他并不知道 => 同上，真相保留在 foreshadows.md 的作者真相栏
她并不知道 => 同上

[summary:suggest]
真相远比这可怕 => 删去空洞预告，用当下异常细节制造压迫感
一切才刚刚开始 => 用具体新线索收尾，不用空泛旁白
```
