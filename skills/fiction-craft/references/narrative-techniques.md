## 一、欲扬先抑（三层级）

先压低、再抬高。压得越具体、越让读者憋屈或轻视，反手抬起来时的落差与爽感就越强。

**基本公式**：`低姿态 / 被轻视 / 受挫 → 角色不动声色或默默蓄力 → 关键节点用事实反转 → 旁观者与读者同时感受到落差`

### 三个使用尺度

1. **微观（单场景 / 单章内）**：立刻兑现的小反转。
   - 示例：顾客把一只浸过水的老怀表甩在柜台上，冷笑说“小铺子修不好就直说，别拆坏了赔不起” → 林砚没争辩，只拿放大镜看了一眼 → 三分钟拆出卡死的游丝，报出表壳内侧二十年前的修补暗记，顾客当场闭嘴。
2. **中观（跨章，3–10 章）**：连续受压后的阶段性翻盘。
   - 示例：前几章房东坐地起价、债主上门施压、熟客怀疑铺子要倒闭 → 中间几章主角安静攒下关键物证与手艺 → 到节点章一次把旧账和核心难题同时揭翻。
3. **宏观（跨卷）**：身份、处境或话语权的彻底逆转。
   - 示例：第一卷只能在街角守着漏雨的小铺勉强糊口、处处看人脸色 → 中期暗中掌握核心线索与人脉 → 后期成为各方不得不登门求助的关键枢纽。

### 禁忌

- **不能只有“扬”没有“抑”**：没有低谷垫底的高峰读起来像报喜清单，很快麻木。
- **“抑”必须具体真实**：不能靠反派无脑降智骂街凑憋屈，而要落在具体利益、现实门槛、信息差或真实困境上。
- **反转必须有前文积累**：靠提前埋下的能力、物件、准备或观察翻盘，而不是临时凭空开挂。

## 二、冲突升级阶梯

在同一条冲突线上，压力只能往上走，不能轻易往回退。

### 八级阶梯

```text
① 平静 → ② 障碍 → ③ 误解 → ④ 困境 → ⑤ 紧张 → ⑥ 危机 → ⑦ 绝境 → ⑧ 反杀 / 收束
```

### 使用规则

- **允许跳级**：高潮段可以直接从 ② 跳到 ⑤，省去铺垫冗余。
- **不要逆行**：已经推到 ⑤ 紧张，就不要突然退回 ③ 误解水两章，除非明确开启一条新冲突线。
- **对抗必须双向**：双方要有来有回，一方单方面碾压超过两场就会迅速失去张力。
- **落差决定精彩度**：⑦ 绝境与 ⑧ 破局之间的落差越大，读者释放感越强。

### 四类冲突与写法要点

| 冲突类型 | 常见形态 | 写法要点 |
|---|---|---|
| **人 vs 人** | 利益博弈、刁难、背叛、竞争 | 通过具体诉求、对话交锋和动作落实，不给对手贴脸谱化坏人标签 |
| **人 vs 自然 / 环境** | 极端天气、地形险阻、生理极限、体系瓶颈 | 用具体体感、时间压力和物理/规则参数写压迫感，不靠空喊“好可怕” |
| **人 vs 系统 / 规则** | 行业潜规则、制度门槛、阶层壁垒、世界铁律 | 冷静呈现规则如何卡死普通人，再通过主角找缝隙或付代价破局 |
| **人 vs 自我** | 怀疑与信任、暴露风险、过往心结、底线抉择 | 心理拉扯默认控制在 300 字内，用实际行动结束犹豫 |

## 三、场景-反应结构（Scene-Sequel）

把叙事拆成交替出现的两个单元，用来精确控制节奏快慢。

### 场景（Scene：行动单元）

1. **目标（Goal）**：角色此刻想达成什么具体结果？
2. **冲突（Conflict）**：谁或什么在阻拦他？双方如何交手？
3. **灾难 / 意外（Disaster）**：结果不是简单成功，而是“是，但出了更糟的岔子”或“否，而且处境更坏”。

### 反应（Sequel：消化单元）

1. **情绪反应（Reaction）**：撞上意外后，角色瞬间的生理与情绪震荡（克制写出，用行为承载）。
2. **两难选择（Dilemma）**：摆在面前的选项都有代价，怎么选都不轻松。
3. **决定（Decision）**：角色敲定下一步怎么做 → 这个决定直接变成下一个场景的**目标**。

### 节奏控制杆

| 想要的节奏效果 | 具体操作 |
|---|---|
| **加速** | 压缩反应段到两三句，或用新的外部意外直接打断消化过程 |
| **减速** | 完整展开反应段，穿插环境细节、人际互动与日常缓冲 |
| **最大张力** | 连续串联 2–3 个场景，上一场的“灾难”直接触发下一场的“目标”，中间完全不给喘息（适合卷高潮、连续危机） |
| **制造呼吸感** | 在两场高强度冲突之间，插入一段完整的反应单元，让情绪落地后再起势 |

**快节奏示例（连续场景无反应段）**：
- 场景 1：进闸房找证物 → 冲突：铁门反锁且灯路失灵 → 灾难：外头传来急促脚步声。
- 场景 2：从侧窗脱身 → 冲突：窗框锈死 → 灾难：借力撬窗时碰落铁盒，惊动来人。
- 场景 3：引开对方保住旧账本 → 冲突：河堤无遮挡 → 灾难：对方认出了林砚手里的钥匙。

**慢节奏示例（完整反应段）**：
- 场景：葛婶来取修好的表，临走把一张旧合影塞进柜台缝里就走。
- 反应：林砚捏着照片站在灯下，指腹在泛黄的边角停了很久（情绪）→ 追出去问会打草惊蛇，装没看见又咽不下父亲那笔糊涂账（两难）→ 他把照片锁进抽屉，决定今晚先去探唐七的口风（决定）。

## 四、期待感管理

读者翻开下一章的核心动力，是心里挂着“还没揭晓的事”。**核心法则：永远同时拉着 2–3 根线**，不要等一根线收完、一切归零后再起新线。

### 50% 规则

当前主期待弧线走到约一半进度时，就开始种下下一条弧线的种子。这样本弧线收束时，读者已经被下一根钩子勾住，不会出现“演完了可以弃书”的断崖感。

### 微观推进（单章内）：设疑 → 给半个答案 → 留更大的疑

1. **设疑**：柜台后的座钟明明没上发条，夜里却自己走过两格。
2. **给半个答案**：林砚拆开后盖，发现摆锤被人换过一块带磁性的异形铁片——不是闹鬼，是有人动过手脚。
3. **留更大的疑**：铁片背面刻着闸房值班编号，而那个编号十年前就注销了。

### 宏观交错（卷与卷之间）

一个大卷下同时挂着短、中、长三类悬念线：
- **短线（3–5 章收）**：眼前的具体麻烦，保证读者每周/每天都有兑现。
- **中线（半卷到一卷收）**：阶段谜团或对手博弈，撑起整卷主心骨。
- **长线（跨多卷收）**：核心秘密、身份真相或大局暗线，提供长期追更粘性。

三条线交替活跃，绝不同时陷入沉寂。

## 五、情绪波形设计

情绪如果一直高亢，读者会迅速疲惫；一直平缓，读者会流失。

### 波浪原则

```text
小高潮 → 低谷缓冲 → 更高的高潮 → 低谷缓冲 → 卷最高潮 → 释放余韵
```

**三条铁律**：
1. 连续两个高潮之间必须安排缓冲低谷，否则第二场高潮的冲击力会被透支。
2. 同一大弧线内，后一个峰值应高于前一个峰值（赌注更大、秘密更深或对手更强）。
3. **低谷不是水字数**：低谷用来消化结果、推进支线、拉近人物关系、铺垫下一次高潮的筹码。

### 完整情绪周期六拍

`好奇 → 期待 → 紧张 → 危机 / 压抑 → 转折 → 释放 / 满足`

排布章节时检查：当前章落在哪一拍？如果连续两章以上停在同一情绪水平（尤其连续平铺或连续硬憋），立刻调整节拍或插入外部事件（具体跨章排布见 `fiction-planner`）。

## 六、涟漪写法

主角做成一件大事后，只写他自己的感受，格局会显得很小。通过**不同距离他人的反应**把影响一层层荡开，叫“涟漪写法”。

| 涟漪层级 | 发生时机 | 写法 | 原创示例（闸房停电夜事件后） |
|---|---|---|---|
| **直接反应** | 当场 / 当天 | 目击者的眼神、停顿、短句和现场动作 | 唐七盯着被撬开的铁盒，半天只吐出一句：“你真敢把灯拉了。” |
| **间接反应** | 1–3 章后 | 周边人的转述、议论、局部秩序变化 | 河堤附近商户传开“旧闸房昨晚冒了火花”，物业连夜换了铁链锁。 |
| **远端反应** | 5–10 章后 | 表面无关者无意提及、上游势力察觉异常 | 城西旧货行突然停收所有带河务编号的旧铜件，背后的人开始排查谁动过闸房。 |

### 禁忌

- **不要全塞在同一章**：把三层反应分散到后续章节，才能制造持续余波。
- **善用“完全不知”的反差**：身边亲近的人完全不知道主角刚经历过生死一线，照常催他吃饭、聊家常——这种“不知”本身就是极强的情感张力。

## 七、区域推进循环骨架

当长篇进入“换新地点 / 进新副本 / 探新势力”的多卷阶段时，很容易写成散点游记（到了新地方 → 看个新鲜 → 顺手收个东西 → 换下一站）。用**区域循环八步**在后台托住结构（注意：这是作者的后台骨架，正文要写得自然，不要写成游戏任务提示框）：

1. **准入门槛**：进新地方先立规矩和排异性，不先写风景和历史。载体可以是预约、凭证、开放时段、行业行规、资格校验。
2. **本地引路人**：给主角一个可信但**有限**的本地接口。他只把主角带进公开层，不负责带飞、不主动抖大真相、不替主角越线兜底。
3. **互惠小任务**：先做一件低风险的互惠小事（核一份旧账、跟一趟日常活、做一次样本对照），让主角长出“这里怎么运转”的第一层手感，避免一来就查大案或当救世主。
4. **找到主节点**：把零散见闻收束到一个中心场所（工坊、档案馆、交易所、总仓、主坛），后续行动围着这个节点反复回返。
5. **区域连锁（2–4 个点位）**：围绕主节点串起 2–4 个关联点位（例如记录链 + 材料链 + 公共规程 + 灰边交易），形成有因果的故事链，而不是一章一个景点打卡。
6. **贴合气质的麻烦**：麻烦必须长在这个地方的骨头里。路线型区域出误导与隐瞒责任，档案型区域出篡改限制语，交易型区域出套壳造假，不要每张地图都靠同一种反派挑衅推动。
7. **收口 / 留线**：按主角身份与本书口径体面收口——未必每次都追凶到底或彻底掀桌，很多时候护住人、保住关键物证、压回规矩并留出后线，反而更真实耐看。
8. **可见结算与再出发**：离开前至少落下两类可见收益（实物/资源、新规则认知、人脉、教训、下一站线索），不能只写“他又长见识了”。

**体量控制**：小区域 3–5 章跑完一轮（每章承担 1–2 步）；中区域 6–12 章；大区域可拆两轮或两卷，但每一轮都要有独立的主节点、麻烦与结算。

## 八、多角色场景与新角色出场

### 视角纪律

- **一个场景 = 一个视角**。第三人称有限视角下，不要在同一场景内跳进另一个人的脑子写“他暗自心惊”。
- 确需切换视角时，先用 `---` 切场，新场景第一句就锚定新视角人物。

### 新角色出场三步公式

让配角一出场就立住，不需要从头到脚写三百字外貌简历，只需三步：

1. **高辨识度锚点**：一个外貌或习惯动作细节（如“说话前先拿袖口擦眼镜腿”“进门先看门闩”）。
2. **定调第一句话**：一句直接露出立场、职业或性格的话，跳过“你好我叫某某”。
3. **首次互动基调**：和主角的第一次小交锋或小合作，定下两人此刻是戒备、互利、敷衍还是默契。

> 示例：老匠人进铺子没先看人，先拿指甲敲了两下柜台玻璃（锚点）。“你这钟摆歪了半度，自己听不出来？”（定调台词）林砚没急着接话，顺手递过去一把小号一字螺丝刀，对方愣了半秒接过去，两人从此算搭上线（互动基调）。
