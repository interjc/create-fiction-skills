## 一、分批写集纪律

以下创作数字均为可调默认，机读格式按契约执行：

- **每批 ≤5 集**：一次写太多容易丢掉前 3 拍张力与人物口吻漂移。
- **每批启动只读四样**：`adaptation-map.md` 本批规划行；上一集的映射行（映射表有 `集末状态` 列时连同这一格）；上一集结尾；本批出场人物与涉及线索的 bible 条目（模式 A 按需打开本批 `来源章` 定稿取细节）。**不要把上一批整套剧本全文塞进上下文**，避免越写越像复述。开场直接在动作里接住上一集的集末状态，不让人物站着复述前情。
- **写完一集就回写映射行**：映射表有 `集末状态` 列时，最迟在该集改为 `定稿` 前填好这一格，写法见改编与分集规划指南里「可选列 `集末状态`」一节；回写时发现这一集结尾接不上下一集规划行，停下来回到映射表改规划，不在下一集里硬补解释。
- **每批写完回看本批与上一批**：并排看破局手段、对抗结构、集尾钩子类型和 `【镜头】` 用法是否连续同型（例如连着几集都靠旁人闯进来解围、都只在原地加码而筹码没有易手、都用同一种强调镜头）。同型连续且观众已能猜到结果时，换用已有关系、已埋证据或升级的代价来破局；同一危机链上相邻集沿用同型钩子属正常，不算重复。
- 文件格式严格按 [SB §9.3](formats/drama.md)：`状态` 仅取 `初稿` / `修改` / `定稿`（新稿填 `初稿`），仅在与 `series.md` 的 `单集时长` 不同时写 `目标时长`。

## 二、开场类型与接续

每集开场先过通则，再按 `series.md` 的 `## 开场类型` 写首拍；没写这一节时按动作冲突型。个别集确需换型时，在该批汇报里向作者说明理由。以下数字均为可调默认。

### 通则（四种类型都适用）

- **首拍立住一个具体的“不对劲”**：一个动作、物件、声响或一行字，让观众在前 3 拍就看出事情不对；靠配乐、天气或形容词“营造氛围”不算。
- **开场 VO（或主角 OS）至多一条**：下一条必须是与它形成反差的动作行；它只补画面给不了的东西，不复述画面。
- **开场五禁**：
  1. 起床、揉眼、拉开窗帘。
  2. 超过约 2 秒的纯行车 / 走路赶路镜头。
  3. 用旁白灌输背景、世界观或人际关系。
  4. 咖啡馆 / 餐桌无冲突闲聊。
  5. 开场第一场涌进多个新人物扎堆报姓名。

### 四种开场类型

| 开场类型 | 首拍形式 | 常见适用题材 | 失败的样子 |
| --- | --- | --- | --- |
| **动作冲突**（默认） | 场景 1 第一条内容行就是主语在运动的可见动作（拧锁、砸表、拦门、抽走凭证），前 3 拍有人在动手、拦人或抢东西 | 复仇、逆袭、动作任务、强对抗的都市与仙侠 | 首拍只是走位热身（推门进屋、放下包），冲突拖到第 3 拍以后 |
| **异常静止** | 一处说不通的字、声音或物件先于人物出场，不靠肢体对抗：字（柜台玻璃上被人用指尖写下的一个日期）、声音（拔了线的座机响起来，录音带末尾多出一句谁也没说过的话）、界面或读数（突然弹出的系统提示、停在不可能位置的仪表指针） | 悬疑、刑侦、规则怪谈、民俗恐怖 | 空镜里什么异常也没有，只有阴沉的天和配乐 |
| **反差旁白** | 一条克制的 VO（或主角 OS）先说，紧接的动作画面与它唱反调；VO 只交代镜头拍不到的那一层：人物脸上赔着笑，VO 里是他真正打的主意；或者一句话认下压了很久的事 | 破镜重圆、年代情感、重生、人物侧写 | VO 讲前史或复述画面；连着两条 VO；接在后面的画面与 VO 同向，没有反差 |
| **生活切片** | 一个平时顺手的小动作这回出了岔子（钥匙插进去转不动、找零差了一张、每天准点的表今天停了） | 温情日常、轻喜剧 | 一家人吃饭闲聊，什么都没出错，等到第二场才有事 |

### 类型默认

- **第一条内容行带运动**只属动作冲突型；其他三型首拍可以是静止的物件、声响或字，但必须带着那个“不对劲”。
- **不用没有异常细节的空镜开场**：异常静止型的空镜里要有一个看得见的异常（停摆的钟、门缝下压着的纸）。
- **非反差旁白型不用 OS / VO 顶场景 1 第一行**：会触发 `drama-check.mjs` 的 `voiceover-open`（对应的 `drama.voiceover.os_max` / `vo_max` 设为 `null` 时脚本不报）。反差旁白型保留时，按机检规则处置指南记「已核对，保留：理由」。

### 接续与第 1 集

- **接住集末状态**：开场从上一集的集末状态（映射行的 `集末状态`，无此列时看上一集结尾）接起：谁站在哪、筹码在谁手里、时限还剩多少，直接落在首拍动作里。
- **接住上集悬念 ≠ 立刻泄完**：除付费首集需在前 15 秒兑现卡点外，常规集的开场要立刻承接上集断章动作，但只揭第一层或立刻引出更棘手的阻力，保持张力不断。
- **第 1 集硬指标（可调默认）**：前约 5 行内说清「谁想要什么 + 具体数字或截止期限」（例如「三天内还清债，不然搬空钟表铺」）。动作冲突型的爽剧 / 逆袭类另要在 **35–45 秒** 内给出主角的第一次有效反击，不能整集挨打。

## 三、节奏结构：90–120 秒四挡与 150–195 秒两轮

### 90–120 秒常规集（四挡，可调默认）

| 时段 | 拍次职责 | 写作要点 |
| --- | --- | --- |
| **0–15 秒** | 抓人 + 亮筹码 | 按开场类型切入，接住上集或立住本集赌注 |
| **15–45 秒** | 正面交锋 | 对手施压、堵路或设局，主角陷入劣势 |
| **45–85 秒** | 亮底牌 / 可见结算 | 主角出招、亮物证或反转局面，给出明确胜负或代价 |
| **85–110 秒** | 余波 + 新钩子 | 结算引发的新麻烦或更大对手露头，停在开放瞬间 |

- **每 15–30 秒有一次可见变化**：筹码加码、证物出现、站位互换、态度倒戈——观众静音看画面也能看出局势变了。
- **禁止换场地继续同一场争吵**：从铺子吵到巷口如果说的是同一层道理，直接合并到同一个空间，把争执往前推一层。

### 150–195 秒长集（两轮回合）

- 按本集目标时长在**约 50% 位置**切分两轮：
  - **A 轮（前半程）**：抓人 → 交锋 → 约 50% 处抛出中段钩子（小翻转或新证据）。
  - **B 轮（后半程）**：承接中段钩子，双方同时加码，打出更强一次结算并抛集末主钩子。
- 全集场景数控制在 **≤3 场**。

## 四、断章收尾

- **最后一拍必须是开放瞬间**：一只伸到半空的手、一句没来得及回答的质问、门后突然响起的异动，**绝不用总结句或抒情句收尾**（如“他知道，真正的较量才刚刚开始”）。
- 最后一个场景之后放恰好一个 `<!-- hook: X -->`（[SB §9.3](formats/drama.md)），其后除卡点集的 `<!-- paywall -->` 外不再有任何剧本内容。

## 五、对白节奏与场数控制

- **对白与动作穿插**：默认每 **2–4 句** 对白（紧张对峙 **2–3 句**）插一条可见动作或反应，打破“站桩念台词”。配置 `drama.dialogue_run_max`（默认 `6`）只是机检上限，不要贴着上限写。
- **一句一口气**：单句台词常规 **≤25 字**，超过 **35 字** 拆成两句并在中间插动作、停顿或对手打断。通用对白潜台词与信息分层技法见 `fiction-craft`（未安装时坚持用动作与停顿承载潜台词，不把情绪直白说满）。
- **场数预算（可调默认）**：
  - 90–120 秒：**≤2 场**。
  - 150–195 秒：**≤3 场**。
  - ≤60 秒：通常 **1–2 场**。
  - 原则：**两分钟换四个地点，不如一个逼仄空间打到底**。配置 `drama.max_scenes`（默认 `5`）只是机检上限。

## 六、可拍动作行与反例改写

### 核心原则

- **见听原则（只写看得见、听得见的）**：一律用现在时，只写镜头拍得出、话筒录得到的动作、物件与声音；**不写气味、味道或脑内想法**，需要表现气味或异常时，改写可见痕迹（油渍、水痕）或人物的可见反应（皱眉抽鼻、掩口后退）。
- **三类禁写**：
  1. **否定伪动作**（如“看都没看”“连眼皮都没抬”“并未察觉”）——镜头拍不出“没发生的事”，改成他正在做的替代动作（对应机检 `UA01–UA04`）。
  2. **微表情**（如“眼神一闪”“眼神复杂”）——竖屏小画幅看不清，改成手上或身体的明显动作（对应 `UA11`）。
  3. **心理活动**（如“心里一沉”；脚本只认部分写法，其余靠人工核对）——动作行不写脑内想法，改成外化动作或道具互动（对应 `UA12`）。
- **道具交代出处**：人物递出钥匙、账本或工具时，先写它从哪拿出来（兜里、抽屉暗格、柜台底下），避免凭空变出来。
- **制作形态约束**：`series.md` 标明 AI 生成视频时，**只写常见日常动作**（推门、放下杯子、转身、递物），避免复杂多人格斗或精细机械拆装连拍。
- **剧本管戏，分镜管拍**：`【镜头】` 行（如 `【特写】`、`【闪回】`）只在叙事必须强调的关键物件或时空切换处慎用；**剧本里不写景别序列、镜号或 AI 提示词**，那些属于 `fiction-storyboard` 与下游提示词阶段。

### 原创反例 → 改写对照（钟表铺世界）

| 问题类型 | 拍不出的写法（反例） | 可拍的写法（改写） |
| --- | --- | --- |
| 否定伪动作 | `△ 唐七看都没看林砚一眼，连头都没抬。` | `△ 唐七背对着柜台，低头把三摞旧零件箱死命往墙角推。` |
| 否定“未察觉” | `△ 葛婶并未察觉柜台底下少了一把钥匙。` | `△ 葛婶把抹布叠方放回柜角，转身拉上门栓；柜底空钩轻轻晃了两下。` |
| 微表情 | `△ 林砚眼神微动，眸色复杂地看着那只停摆的座钟。` | `△ 林砚捏紧镊子停在表盘上方，指节泛白，慢慢把镊尖移向停在三点十分的分针。` |
| 心理活动 | `△ 林砚心里一沉，明白唐七一定在瞒着债主的事。` | `△ 林砚盯着唐七发抖的右手，顺手把座机听筒按回机身，堵住门边。` |
| 道具无出处 / 写气味 | `△ 林砚突然递给葛婶一把沾着煤油味的旧钥匙。` | `△ 林砚拉开柜台暗格摸出那把还滴着煤油亮渍的旧钥匙，推到葛婶手边；葛婶低头抽了下鼻子，手猛地缩回。` |

## 七、对抗戏与破局

本节是技法默认：复仇、逆袭、商战类正面对抗多，悬疑、日常、温情类不必每场都正面交锋，那些戏按信息增量、张力或关系变化来判。

### 对抗四步

1. **诉求具体**：发起方要办成一件画面里看得见的事（抬走一台钟、逼对方签字、拿回一张单据），并且办不成有代价。
2. **阻力有花样**：对手不只说“不行”，而是换招——岔开话头、开出交换条件、抽走对方依仗的东西、质疑证据从哪来、抬高闹大的代价、把旁人拉进来。
3. **局势换手**：一方被逼出新动作后，双方手里的筹码对比变了，不是同一层道理再吵一遍。
4. **落定即切**：结果或立场刚落定就切走，余波留给下一场或集尾钩子。

### 判断要点

- **谁占上风看筹码，不看音量**：握着决定性证据、能叫停谈话、能把事情公开、退路更多或闹大损失更小的一方占上风。嗓门最大的人往往是筹码最少的人。
- **权力转移要有动作确认**：换手的那一刻，用一个可见动作坐实——把东西放回去、交出钥匙、改了称呼、让开门口、掏出电话找人帮忙。只靠台词宣布“你输了”，观众看不出来。
- **台词是棋**：每句台词都在走一步——逼、挡、探、压、护。走不出一步的台词删掉；挨了一句重话，要落到具体结果上（说漏一句、改了主意、退了半步），不能听完照旧。
- **破局要挣来**：解局的东西必须是前文已交代的证据、权限、代价或人物选择，不靠对手突然闭嘴走人，也不靠天降外援。
- **巧合三条件**：只用来添麻烦，不用来解围；前文在同一地点或同一层关系里埋过；同一条因果链上不再叠第二次好运。
- **误会要有硬理由**：误会得经得起观众追问“他为什么不知道”，并且真让人吃了亏；一句话就能说开的误会，不要撑过一集。

### 原创正误对照（钟表铺世界）

前提（前文已交代）：第 1 集已立下三天期限——三天内还清债，不然搬空钟表铺；唐七一直瞒着债主的事；第 1 集结尾，林砚从那台停在三点十分的座钟底壳里取出半枚黄铜工号牌，唐七不知道。

**反例**（只比嗓门，靠天降外人破局）：

```text
△ 唐七一把抱起柜台上的座钟。
唐七：这钟今天我必须带走！
林砚：放下！
唐七：我就不放，你能拿我怎样？
林砚：（提高嗓门）我让你放下！
△ 门外突然闯进一个陌生男人，说这钟是他寄存的，唐七把钟放回柜台，转身走了。
```

问题：唐七为什么非带走不可、带不走会怎样，一句没交代；三轮台词只是音量升级，没有筹码交换；解局的陌生人前文从未出现，林砚的胜利不是挣来的。

**改写**（诉求有赌注，筹码换手，破局来自前文物证）：

```text
△ 唐七抱起柜台上那台停在三点十分的座钟，往门口走。
唐七：债主松口了，三天的期限能缓，条件是今晚把这台钟送过去。
△ 林砚站在柜台后，拉开抽屉，把半枚黄铜工号牌拍在玻璃上。
林砚：满铺子的表他一块不挑，只要这台停摆的。他要的是钟肚子里这个。
△ 唐七停在门槛上，回头盯住铜牌。
唐七：……你拆过了？
林砚：你抱一台空钟过去，期限照样是三天，还得多给他一个解释。
△ 唐七把座钟放回柜台，两手仍按在钟壳上。
唐七：那你说，怎么办。
△ 林砚把铜牌揣进工装内兜，拎起座机听筒递到唐七面前。
林砚：打给他。就说钟在修，明早才能取。
```

为什么成立：唐七的诉求和赌注第一句就亮明（拿这台钟换缓期限）；林砚的判断来自两件已有事实——债主点名只要这台停摆的钟，而钟里取出过铜牌，不是凭空猜中；他不跟唐七比嗓门，而是抽走对方真正依仗的东西（钟里已经空了）；上风换手由“停在门槛—把钟放回—改口问怎么办”三个动作确认；解局的铜牌是第 1 集已交代的物证；收在林砚逼唐七打电话拖时间这个明确的下一步上，三天期限仍悬着，留给集尾钩子。

## 八、OS 与 VO 使用边界

OS / VO 在开场的用法以「开场类型与接续」一节为准，本节管全集。`drama-check.mjs` 的识别口径：对白行角色名后的括号内容按 `，` `,` `、` `/` 和空白拆词，任一词**不区分大小写全词等于** `OS` 或 `VO` 才计入；角色名为 `旁白` 的行算 VO；角色名为 `字幕` 的行不计入 OS 或 VO。配置默认 `os_max: 2`、`vo_max: 1`（90–120 秒常规集建议 OS ≤1，旁白主导剧可在配置设为 `null`）。

### 五类允许用途

1. **委屈立住**：主角表面忍让，一句极短 OS 亮出受屈底线。
2. **点题转折**：局势翻转瞬间点破核心反差，不超一句。
3. **一句立人设**：新角色立住反差性格的一句短评。放在场景 1 第一行只属反差旁白型（至多一条，下一条接反差动作）；其他开场类型放到首拍之后。
4. **说不出口的心事**：**必须与当下动作形成反差**（手上在笑脸递茶，心里却在算对方的破绽）。
5. **时间 / 年龄坐标**：用极短 VO 交代跨年或时限跳切（如「旁白：三天后，冬至前夜。」）。

### 五类禁用场景

1. 用 OS / VO 灌输世界观、前史设定或人物关系。
2. 复述画面刚刚已经演完的动作。
3. 替代人物正面交锋（能当面吵出来就不藏进内心独白）。
4. 连续出现两条 OS / VO。
5. **紧贴断章钩子**充当解释或总结。

### 判例对照：集末钩子前的 OS 怎么改？

假设第 1 集结尾，林砚拧开座钟底壳，滚出半枚刻着工号的黄铜牌：

- **应改写（前史灌输型 OS 紧贴钩子）**：
  `林砚（OS）：十五年前秋汛夜里，我爸在闸房值班的工号就是零七，这钟里怎么会有他的牌子？`
  问题：借 OS 替观众背前史设定，又贴在断章钩子上泄掉画面悬念。
- **改法（去 OS、画面化落钩）**：
  `△ 林砚用镊子把黄铜牌翻面推到台灯下，另一手拉开抽屉，把泛黄值班卡上的「零七」并排按在旁边。`
  `△ 卷帘门外突然响起三声极慢的敲门声，林砚捏着铜牌的手猛地停在灯下。`
  如果整场确实需要一句极短反差 OS 点破心事，只能放在本场中段与动作形成反差处，**其后必须接可见动作或新异动再落钩子，绝不把 OS 紧贴在断章钩子上**。

## 九、人物口吻与改稿纪律

- **口吻来源与优先级**：按 [SB §3](formats/project.md) 第 10 条（`AGENTS.md`「本书口径」> `bible/style-guide.md` > skill 默认），结合 `bible/characters.md` 的说话风格 / 口头禅，以及 `bible/character-dynamics.md` 最新一行的关系现状定语气。
- **遮名测试**：写完一场戏，遮住每句台词前的角色名重读一遍——如果分不清哪句是林砚、哪句是唐七、哪句是葛婶，说明台词同质化，必须按各自身份与习惯重写。
- **改稿连锁检查**：修改剧本里的任何一拍后，重读它前后相邻的拍次，逐项核对三件事：(1) 人物站位有没有瞬移；(2) 手里的道具还在不在、放哪了；(3) 场内站着谁、谁已经出门了。
