# AGENTS.md — 《停摆的钟》项目规则

本项目是《停摆的钟》的写作仓库，遵循 `docs/spec/story-bible.md` 约定的目录结构与机读格式。所有设定、时间、人物、伏笔与短剧映射均以 Markdown 为唯一权威。

## 本书口径

- **题材与基调**：现代都市悬疑，南方河岸小镇（清湾镇），克制、冷峻、重物证与生活质感，不搞超自然或玄学反转。
- **叙述视角**：近距离第三人称限知，原则上只贴主角林砚的所见、所闻与推断；不得上帝视角提前泄底。
- **主角口径**：林砚，二十六岁修表匠，少言、克制、不抽烟，习惯先看物证再表态，爱用钟表零件与齿轮咬合理解人事，不做情绪宣泄式独白。
- **信息与真相隔离**：涉及十五年前闸房旧案与人物秘密的内容，严格区分“读者已知”与“作者真相”；未到计划章不得在正文中提前漏底。
- **正文禁区**：
  - 禁止精确公历年份与日期（只用相对时间与节气，如“那年霜降刚过”“十五年前”）。
  - 禁止出现 `.fiction/config.json` 中登记的现实原型地名（如安洲市、永宁县），正文一律模糊化。
  - 禁止天气/景物套话开篇、作者替读者总结句、AI 腔套话，禁止连续 4 句以上无动作对话。
  - 正文不得出现任何内部文件名、伏笔/支线/锚点 ID 或写作术语（如“伏笔”“钩子”“大纲”）。
  - 每章结尾须以具体悬念、新信息或局势转折收束，禁止用“做笔记、列计划、回去睡觉”结尾。

## 项目工作流

1. 写新章前先读最小必读集：本文件 → `chapters/{vol}/vol-info.md` → `bible/volumes/{vol}.md` → `bible/canon.md` → `brief.mjs` 输出 → 上一章结尾。
2. 先建 `{ch}/resources.md` 与 `{ch}/outline.md`，确认场景五要素、伏笔与支线动作、钩子级别后，再写 `v1.md`。
3. 正文写完后运行字数与硬规则扫描（`length.mjs`、`lint.mjs`），达标后立即按事件回写 `appearances.md`、`foreshadows.md`、`subplots.md`、`character-dynamics.md`、`storylines.md`、`inventory.md`。
4. 改编短剧时以 `drama/stopped-clock/adaptation-map.md` 为短剧侧主写入口，不回写小说伏笔表。
